1. `pip install -r requirements.txt`(numpy/cv2/scipy/triangle/psd_tools 全 ok)。
2. 解析 Award.json:確認機器人 3 mesh 件皆為 **weighted**(光暈 78v/身體 98v/左手 80v),且**無 deform timeline**。

4. **踩座標系 bug**:第一版把藝術家 uv 當 atlas-page 正規化 → 減 region xy → 身體 IoU=0.0 假性失敗。
   印 uv 值域發現 uv 跨滿 [0,1] → **Spine JSON mesh uvs 是 region-local 正規化**(runtime 才 remap 進 atlas)。
   改為直接把 uv 當件圖正規化座標(與 generate_mesh_v2 同座標系)→ 三件全對齊。
5. 校準判別力驗證:身體 8 候選 identity 0.939 遠勝次高 0.603 → 對齊非偶然。
6. 固化成可重現工具 `tools/mesh_gen/compare_to_award.py`(exit 0 = PASS)。

## 關鍵結論 / 教訓

- **教訓(再一次)**:先驗證座標假設(印值域)再套幾何;先前也栽在 stress_field / 白底 / derotate 方向。
