## 自我驗證迴圈(踩到 + 修正)

1. **誤映射被自我檢查抓到**:初版把 mesh `uvs` 當 atlas page-space → 藝術家自身覆蓋率崩到
   0.0~0.54(`mapping_ok=false`)。查 uvs 值域為全頁 [0,1] → 證實 Spine mesh uvs 是**來源圖局部**
   座標(runtime 才 remap 進 atlas)。改用去旋轉件圖 `(u*W,v*H)` 映射 → 藝術家覆蓋率回到 0.97~0.98。
2. **blob 件覆蓋率不足 → 單一參數泛化**:光暈初驗 0.929 < 藝術家(hull 僅 14,內接多邊形低估凸弧)。
   epsilon 掃描 3 件一致單調 → 選 **0.002** 為單一泛化值(非逐件調),3 件全 ≥ 藝術家且更精簡。
   設為 `generate_mesh_v2` 回退 Delaunay 的預設(`v1_epsilon=0.002`);v1 自身預設維持 0.008。
3. **無回歸**:main_draw curtain_left/shadow(v2 strip)重驗仍 overall_pass;v1 直呼預設未變。

## 決策 / 發現

- Spine mesh `uvs` = 來源圖局部 [0,1](寫進 knowledge,未來讀寫 mesh 一律照此)。
- 這 3 件是 **weighted + 無 deform timeline** → 真實 deform 閘 **N/A**(拒用未校準合成場)。
  幾何層已驗收,**權重生成(BBW)是下一個明確缺口**。
