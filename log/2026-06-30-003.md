# 2026-06-30 — session 003

## 這次做了什麼（自動配權 bone-distance heat：S3→S5 銜接）

接 STATE 候選 #3（上一塊完成後升為最高優先）：讓 S3 的 unweighted mesh 可被**多骨**驅動。

1. **新工具 `tools/mesh_gen/auto_weight.py`**：
   - **骨鏈**：沿 mesh 點雲較長軸等距佈 n 根骨（root→tip）。
   - **配權 = bone-distance heat**：頂點對各骨段距離 → `1/(d+eps)^power` → 留最近 k 根 → 歸一
     → 沿 mesh 邊 Laplacian 平滑 → 再歸一。
   - **bind 座標**：setup 下頂點在該骨局部座標 `R(-θ)·(v-o)`；輸出 Spine weighted vertices
     `[n,(boneIdx,bindX,bindY,weight)*n]`（hull 排最前、每頂點權重和=1）。
   - **FK+LBS**：forward kinematics + 線性混合蒙皮，供閘做彎折變形測試。
2. **自驗閘**（復用 `deform_eval` 自交/翻面幾何閘）：
   - AC1 partition-of-unity（權重和=1、≥0、bones/vertex≤4）；
   - AC2 setup 重建（LBS 在 setup 位姿還原 setup 頂點，誤差 ≤0.0027px，門檻 0.05px——殘差來自 bind 存 3 位小數）；
   - AC3 deform 掃描（沿骨鏈漸進彎折 ±10..60°，0 自交/0 翻面/0 退化）。
3. **驗證**（2 個真實衍生 mesh）：curtain_left strip（30v/3骨）、robot 左手 blob（67v/2骨）
   → **3 AC 全過，彎折 60° 掃描 0 自交/0 翻面**。

## 評估器可信度（校準，必做）

- **真值自一致性**：Award **7 個真實 weighted 件** partition-of-unity 全 OK（權重和 ∈ [0.99999,1.00001]），

  → 閘**有鑑別力**。正過/負敗內建進 `python3 auto_weight.py`（無參數自測，EXIT 0/1）。

## 關鍵結論 / 教訓

- **平滑是關鍵**：inverse-distance + top-K + **沿邊 Laplacian 平滑** → 變形平滑無撕裂；
  硬單骨指派在關節處必撕（負對照證實）。
- 這是 **bone-distance heat**（確定性純 CPU），非真正 **BBW**；對「骨鏈帶 strip/blob」已足夠，BBW 列後續。
