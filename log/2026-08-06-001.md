推進 STATE「下一步候選 1」:把 S3 mesh 生成器對**真實生產 spine 的 mesh 件**(Award「機器人拆件」
光暈/身體/左手,皆 weighted mesh)做端到端靜態覆蓋 IoU 驗收。

1. **對象分析**:確認 3 件在 Award 皆 **weighted mesh 且無 deform timeline**(骨/權重驅動);
   藝術家 mesh 78/98/80 頂點。
2. **frame 對齊(驗)**:Award mesh `uvs` 是 **region-local 正規化**(非 atlas-page UV,推翻先前保守假設);
   `atlas_crop.extract`(多頁 + CW derotate)切出的 upright mask 與 uvs 同框 → 藝術家 mesh 對自身 alpha
   IoU 0.97~0.98(對齊正確)。
3. **新工具** `validate_against_award.py`:atlas 切件 → 生成 mesh → AC1 IoU vs alpha,對照 `artist_iou` baseline;
   對 weighted/無 deform 件把 deform 閘標 `applicable=false`(誠實,不用未校準 stress 場)。
4. **首輪結果(預設 eps=0.008)**:身體/左手 gap −0.008(近 baseline)、**光暈 gap −0.050(真實不足)**;
   且 v2 auto 對 blob 自動退回 v1(strip 只在條狀啟用)→ v1/v2 同結果。
5. **查因 + 修正(自主迭代,objective criterion)**:epsilon 掃描證實固定 `epsilon_frac=0.008` 對
   **有機輪廓在生產解析度**下 hull 過稀;eps≈0.002 時 hull 收斂到藝術家量級且覆蓋達標。
   → 新增 `generate_mesh.generate_adaptive`(自 0.008 起加細至覆蓋 IoU≥0.98 或頂點觸頂)。
6. **驗收**:`--gen adaptive` 3 件全 pass(gap +0.004~+0.014,exit 0);**回歸**:main_draw curtain_left v2
   仍 overall_pass(0 自交),adaptive 對 curtain_left 選 eps=0.004、IoU 0.99、44v。
