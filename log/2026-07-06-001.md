# 2026-07-06 — session 001

## 這次做了什麼(S3×S4 端到端對 Award 真實 mesh 驗收 + evaluator-driven auto_tune)

推進 STATE 候選 #1(最高優先、有真值):把 S3(mesh 生成)串接 S4(PSD/atlas 切件),對 Award
「機器人拆件」的 3 個真實 mesh 件(光暈/身體/左手)做端到端驗收。

### AC(先定,可自量測)
在同一張 alpha(atlas 切件)上,與 Award 藝術家真實 mesh 比對:
- **AC-cover**:生成 IoU ≥ 藝術家 mesh 自身 IoU(真實生產基準)。
- **AC-econ**:生成頂點數 ≤ 藝術家頂點數。
- **AC-topo**:0 退化 / 0 孤兒 / 重心≥99% / 格式合法。
- **AC-deform**:誠實判定為 **N/A** —— 這 3 件在 Award 無 deform timeline(靠骨骼權重),
  unweighted 生成器不產權重,無法用真實位移場轉移閘比對。

### 過程(evaluator-driven 迭代,1 輪收斂)
1. 寫 `compare_award_mesh.py`:atlas 切 alpha → 生成 → 對藝術家 mesh 算 IoU/頂點/拓樸。
2. 初測(v2 auto 固定 eps=0.008):econ 全過,但 **cover 全略低於藝術家**(0.929/0.968/0.960
   vs 0.980/0.976/0.968),光暈有 1 孤兒頂點。
3. epsilon 掃描揭示:**覆蓋率由 hull 取樣密度決定,且所需密度形狀相依** —— 無單一 eps 同時過 3 件。
4. 建 `auto_tune.py`:evaluator-driven 從粗到細掃 epsilon,回傳第一個 IoU≥藝術家基準的最精簡 mesh
   (受頂點預算約束)+ `prune_orphans`(保證 0 孤兒)。**不改 v1 本體**。
5. 重驗:**3 件全 overall_pass**(光暈 eps0.002 v78=藝術家、身體 eps0.004 v69 −30%、左手 eps0.006 v64 −20%)。
6. 回歸:main_draw 4-mesh(curtain_left/right/shadow)v2 驗證仍過(shadow2 因與 shadow 共用 region 的既有命名
   quirk,非本次改動)。

## 關鍵結論
- **S3+S4 串成端到端,對真實生產標的(有 ground truth)驗收通過**(里程碑):生成 mesh 覆蓋率
  ≥ 藝術家、頂點數 ≤ 藝術家、拓樸乾淨。
- **固定 epsilon 不通用** → 需 evaluator-driven 自動收斂(auto_tune):這正是 RULES「評估器即自主收斂閘」
  的落地;頂點預算改以藝術家真值為準(舊固定 64 低於藝術家 78/98/80)。
- **誠實邊界**:這 3 件靠骨骼權重變形(無 deform timeline),AC-deform 對它們 N/A;變形穩健度已在
  main_draw 有 deform 的 4 mesh 驗過。weighted(BBW)生成仍是未建能力。
