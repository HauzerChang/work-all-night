## 這次做了什麼(S3+S4 端到端:PSD 件 → 生成 mesh → 對照 Award 生產 mesh)

推進 STATE 下一步 #1(最高優先,有真值可比)。把 S4(PSD 切圖)與 S3(mesh 生成)串成端到端,
用**第二組獨立真實真值**驗 S3:機器人拆件 `robot_parts.psd` 的三件 mesh(光暈/身體/左手)
⇄ 生產 spine `Award.json` 對應的 mesh。

### AC(動手前定)
- 對三件:`generate_mesh_v2`(auto)生成 mesh 的覆蓋率 ≥ 藝術家生產 mesh 覆蓋率 − margin(0.03),
  且靜態閘(格式/重心/退化/孤兒/預算)全過。deform 閘 N/A(Award 這批無 deform timeline)。

### 過程與自我驗證
1. 新工具 `tools/mesh_gen/validate_psd_to_mesh.py`:切件→生成→靜態評估(對切件 alpha)
   + 藝術家 mesh 覆蓋率基準。
2. **評估器校準(第四次教訓)**:初版把 Award mesh uvs 當 atlas 頁 uv → 藝術家基準假性崩到 0.23。
   實測 uvs 是 **region-local [0,1]** 且對應 **de-rotated** 方向。改用 `atlas_crop.crop_region`(CW)當輪廓、
   uv 直接光柵化(免翻轉)→ 三件基準自洽 0.98。**先確認基準可信再下判定**。
3. **iterate**:光暈(大、軟邊發光)在固定 epsilon 下 hull 僅 16 點、IoU 0.933(<0.95)。
   - 加 **自 tune 輪廓密度**(`generate(target_iou=...)`,v2 Delaunay 回退預設 0.96)→ 0.961。
   - 靜態閘揪出 2 孤兒頂點 → 加 **`prune_orphans`**(保 hull-first)→ 靜態全過。
4. **回歸**:main_draw 4 mesh(strip 模式,不受 v1 改動影響)`validate_against_real --gen v2` 全 `overall_pass`、
   deform si=0、IoU 對齊原基準。shadow2 用共用 region 名 `image/shadow`。
