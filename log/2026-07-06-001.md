# 2026-07-06 — session 001

## 這次做了什麼(S3×S4 端到端:PSD件 → S3 mesh → 對照 Award 藝術家真實 mesh)

推進 STATE 最高優先候選 #1:把 `robot_parts.psd` 的 3 個 mesh 件(光暈/身體/左手)切件後跑
S3 生成器,與生產 spine `Award` 的藝術家真實 mesh 做**同一 alpha 上的覆蓋 IoU** 對照(有 ground truth、純 CPU)。

### AC(動手前定)
- 生成 mesh 靜態覆蓋 IoU **≥ 藝術家同件 mesh 的 IoU**(以其自身 uvs 對同一 alpha 量)。
- 生成 mesh 靜態乾淨(0 退化 / 0 孤兒 / 重心全在內)。
- 頂點數 ≤ 64 預算。

### 過程與發現
1. **先破除 STATE 的過時假設**:實測 main_draw 與 Award 的 mesh `uvs` **本就是 region 局部 0..1**
   (Spine JSON 存局部 uv、runtime 才映射到 atlas page)→ **不需 atlas UV 轉換**。省掉舊 TODO 的複雜度。
2. Award 這 3 件皆 **weighted(骨骼驅動)且無 deform timeline** → 靠骨變形、非逐頂點 deform
   → 只做**靜態覆蓋 + 拓樸**比對(誠實範圍;deform 穩健由窗簾 strip 那條線負責)。
3. 初跑:光暈 0.933<0.949、左手 0.964<0.977 **fail**;身體 0.983>0.948 pass。生成 hull 太疏(16/20/19)。
4. **epsilon 掃描定位根因**:覆蓋 IoU **由 hull(邊界取樣密度)決定,內部點完全不影響**
   (max_interior 10/20/25 → IoU 不變)——與窗簾「IoU 由 rows 決定」同一規律。
5. **校正生成器 `generate_mesh.py`(v1)**:(a) 新增 `drop_orphans()` 移除孤兒頂點 + 索引重映
   (凹形件 filter 後凹口邊界頂點會孤兒);(b) 預設 epsilon 0.008→0.004、max_interior 40→24
   (頂點預算**優先給邊界**)。
6. **重跑:3/3 PASS**,且生成 mesh 覆蓋 IoU **≥ 藝術家、頂點只約 45–55%**。

### 取捨與定位(重要)
- **hull 越密 → 覆蓋越高但大 deform 越易自交**。校正後 v1 curtain_left `--gen v1` IoU 0.99 但 deform 自交。
  這**非新退化**:窗簾走 **v2 strip**(auto 分流),v1 從不服務窗簾,且「v1 對窗簾 deform 不通用」早有定論。
- 明確定位:**v1(細 hull Delaunay)= 靜態/骨骼驅動有機件**;**v2 strip = 逐頂點 deform 件**。
