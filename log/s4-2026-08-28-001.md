# 2026-08-28 — S4 session 001(第一次執行,SETUP→ACTIVE)

## 這次做了什麼

S4 排程首次執行(`handoff_S4.md` §5 chunk 0):**補圖閘 v1 + Level 1/2 CPU baseline(邊緣外擴 /
cv2.inpaint),對真實件跑合成挖洞測試,量化「CPU 補得動 / 補不動」的邊界**。

### 1. 新增 `tools/mesh_gen/inpaint_eval.py`

- 合成真值法:載入真實件 RGBA → `punch_hole`(`interior` 內部洞 / `edge` 咬邊界洞)→ 用 baseline 補
  → 與真值比對 `premult_mae` / `alpha_mae` / `seam_grad_diff`(洞邊界環狀帶 Sobel 梯度差)/ `ssim`
  (自實作窗口化 SSIM,環境無 skimage)。
- Baseline:`fill_nearest`(Level 1,`scipy.ndimage.distance_transform_edt` 最近有效像素外擴)、
  `fill_cv2_inpaint`(Level 2,Telea / NS)。
- 正對照 `gt`(填真值)、負對照 `none`(不補)/`random`(亂補);內建 `calibration_check`,
  負對照若意外 pass 則整份報告判定不可信(呼應 RULES.md 三次 miscalibration 教訓)。

### 2. 對真實件(`robot_parts.psd` 切件,由 `psd_slice.py` 產出)跑閘

- **校準先過**:所有測試件的 `gt` 皆完美(mae=0/ssim=1),`none`/`random` 皆明顯 fail(ssim<0.1)→
  指標可信。
- **光暈**(柔和放射漸層):interior 洞(占內容 12%)三個 baseline **全 PASS**(ssim 0.99~0.998);
  edge 洞(咬輪廓)明顯更難,三個 baseline 皆壓線或 fail(ssim 0.71~0.76)。
- **身體 / 左手**(機械面板/高光/接縫紋理):**掃過 5 種洞大小(占內容 2%~12%)+ interior/edge 兩種模式,
  全部 fail**(ssim 上限 ~0.51)。關鍵發現:**洞縮到最小(1517px)仍 fail**,證明失敗原因是「洞落在
  高頻結構區」而非洞太大 — CPU 1–2 級補不動這類缺口,需升 Level 3(LaMa)或 Level 4(人工/GPU)。
