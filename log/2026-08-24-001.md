# 2026-08-24 — session 001

## 這次做了什麼:S3 weighted mesh 骨骼變形驗收(補上唯一未驗維度)

前一里程碑(`s3-robot-mesh-vs-award.md`)誠實標記的唯一未驗維度是「weighted mesh 骨骼變形平滑度」
(靜態 IoU 不涵蓋)。本 session 把它補上。

### AC(動手前定義,可機讀)
- **AC-W1 clean**:我方生成的 weighted mesh 在真實動畫骨 pose 下,可見幀 0 自交 / 0 翻面 / 0 退化。
- **AC-W2 smoothness**:三角面積 CV 與美術同量級(≤ 美術 ×1.5)。
- **前置**:評估器本身可信 — 對美術生產 mesh `_checker_validated=True`,且負對照能抓到壞損。

### 產出(4 支新工具)
- `tools/mesh_gen/spine_skeleton.py` — Spine 3.8 骨架 FK(normal 繼承世界矩陣 + 緊湊 bezier 內插)
  + weighted 蒙皮(bind 局部 → 世界)。
- `tools/mesh_gen/weighted_deform_eval.py` — weighted 變形評估器 + **可見性 gating**
  (attachment timeline + slot color alpha)。校準:`artist` → checker_validated;`neg` → 抓到壞。
- `tools/mesh_gen/generate_weighted_mesh.py` — 拓樸(約束 Delaunay)+ 內部取樣密度控制 +
  inverse-distance^2 BBW 代理權重 + 世界→bind 反算。
- `tools/mesh_gen/validate_weighted_gen.py` — 整合 AC 閘(`_all_pass=True` → exit 0)+ 密度 sweep。

### 量化結果
- 美術校準:3 件 × 2 動畫(Legend_In/Loop)可見幀全 `all_clean`,worst 全 0 → **checker_validated=True**。
- 負對照(身體 1/3 頂點權重換遠端骨):**3702 自交** → 有鑑別力。
- 生成件:左手/身體/光暈 **AC-W1 全乾淨**,`_all_pass=True`。
- 密度槓桿(身體):spacing 40→32→26 ⇒ nv 107→137→175,全程乾淨,CV 0.557→0.368。

### 兩個關鍵發現
1. **校正 STATE 舊假設**:這 3 件其實**有** bone 變形動畫(只有 `Award_Legend_In`/`_Loop` 驅動,
   其餘 10 支不動它們)→ 有真實變形場可對照。
2. **雷點 #2/#3 實證(重要)**:光暈爆開折疊(71 自交)全發生在 slot alpha=`ffffff00`(不可見)幀;
   t=0.6333 才 fade 進。變形閘**必須先過 attachment + alpha gating**,否則生產美術 mesh 假性失敗。

## 誠實限制
- AC-W2(面積 CV)是**弱代理**(均勻格點天生偏低);嚴格閘是 AC-W1,鑑別力由負對照證實。
- 骨「集合」沿用美術真值;權重為 inverse-distance 代理(非真 harmonic BBW)。
