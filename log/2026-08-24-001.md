# 2026-08-24-001 — S3 weighted-mesh deform 評估器(候選 2a)

## 目標(AC-first)
補上 `s3-robot-mesh-vs-award.md` 標記的唯一未驗維度:weighted mesh 的**骨骼變形品質**
(靜態 IoU PASS ≠ bone-driven 變形平滑度)。依 RULES「每能力必配評估器」,先做評估器再做生成器。
- AC1:Spine 骨骼 world-transform 正確 —— setup pose 多骨頂點各骨預測世界點吻合(<0.5px)。
- AC2:動畫 apply 正確 —— t=末幀回 setup(disp≈0)、逐幀連續無跳變。
- AC3:對 3 件真實動畫逐幀跑幾何閘,記錄藝術家變形包絡。
- AC4:負對照(打亂權重)使度量顯著改變 → 具鑑別力。

## 做了什麼
- 新增 `tools/mesh_gen/weighted_deform.py`:純 CPU 重現
  (1) 骨骼 world transform(transform=normal;Award 77 骨全 normal)
  (2) 動畫 bone timeline apply(rotate/translate 加成、scale 乘成 + 緊湊 bezier/stepped/linear)
  (3) weighted `computeWorldVertices`(Σ weight·worldBone·bind)
  對 Award「機器人拆件」光暈/左手/身體 3 weighted 件,在有 pose 到其綁定骨的動畫上逐幀評估。
- 重用 `deform_eval.py` 的 `signed_area`/`eval_pose`(自交/翻面/退化/面積閘)。

## 結果(`weighted_deform.py --negative` → exit 0)
- **AC1 全過**:多骨 bind 一致性 0.037 / 0.014 / 0.014 px(< 0.5)→ 骨骼變換數學正確。
  此檢查 frame-invariant、對全域座標框不變,不需外部真值即自證。
- **AC2 自證**:Legend_In 末幀 disp 精確回到 0.0;逐幀 disp 連續(排除 bezier/區間 bug)。
- **AC4 全過**:打亂『骨↔bind 配對』→ 一致性爆到 287~654px、幾何全壞 → 鑑別力確立。
- **AC3 記錄藝術家包絡**:不透明件(左手/身體)藝術家 mesh 全乾淨(si=0/flip=0);
  **軟光暈在 Legend_In 入場刻意大幅重疊自交**(si=71/flip=7/area 0.89~1.98/maxdisp 676px,
  源於 4_LEG6 起手 scale 1.667× 收回)。

## 關鍵決策/發現
- **自交是「每件校準」閘,不是通用硬閘**(誠實界定,非 bug):AC1 精確 + 末幀回 setup +
  逐幀連續 三重佐證動畫 apply 正確;光暈自交是 additive/半透明軟光暈的視覺無害刻意變形,
  呼應 S3 生成階段光暈需 `boundary-dense soft-band` 特例。
- 採「不劣於藝術家」baseline 哲學(同 compare_robot_mesh 的 IoU margin):以藝術家自身變形
  包絡當每件真值;硬閘只保 AC1 + AC4 + 不透明件乾淨(正對照)。
