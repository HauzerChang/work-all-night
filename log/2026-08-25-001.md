## AC(動手前定義)
1. 能用程式重現 Spine 3.8 蒙皮,對 Award 3 個 weighted mesh 件(光暈/左手/身體)算出任一 pose 的世界座標。
2. 藝術家 mesh 在**真實動畫 pose**下拓樸乾淨(0 自交/翻面/退化)→ 驗證蒙皮數學 + 建立平滑真值。
3. 負對照(壞權重)在藝術家仍乾淨的振幅下出現可偵測缺陷 → 證明閘有鑑別力(非永遠 pass)。

## 關鍵發現 / 決策
1. **In/Out ≠ 變形品質訊號**。初版用合成 graded 旋轉當 pose → 藝術家 mesh 自己就自交(誤判)。
   改用真實動畫 timeline 後發現:In/Out 是入/出場整體 squash/pop 過場(光暈 Legend_In **t=0 就 si=71**、
   Legend_Out 縮到 area **0.169** 消失),原始 mesh 幾何本就自交、是可接受的極短過場 → **只報告**。
   **Loop=穩態律動才 must-be-clean**(4 支 `*_Loop` 對 3 件全程 0 自交)。這把 RULES「用真實而非合成
   stress」原則推廣到 **bone pose**,並加「分辨過場 vs 穩態」。
2. **蒙皮數學由真實旋轉反證**:若 bone transform 寫錯,真實 Loop 旋轉會讓 mesh 爆掉;3 件全程乾淨 →
   蒙皮正確。procrustes_rms(setup vs uv)僅作 sanity(左手 0.087/身體 0.053 顯示 mesh 與貼圖 uv 非純相似,
   屬美術決定,不當閘)。
3. **負對照=硬綁最近骨**:骨界不連續造成撕裂;各件鑑別振幅(左手 real、身體 ×2、光暈 ×5)反映 Loop 幅度。
4. **效能**:geom_fast 與 reference 990 poses **0 mismatch**;身體單 sweep 22s→1.1s(~20×),全閘 ~24s。
