# 2026-07-16 — session 001

## 這次做了什麼(排程 session:S3 端到端 Award mesh parity)

推進 `STATE.md` 最高優先候選 #1:**PSD件 → S3 mesh → 對照 Award 真實生產 mesh**。
這是專案第一個「有藝術家 ground truth 可比」的 S3 端到端驗收。

### AC(動手前先定)
對 Award 3 個 weighted mesh 件(光暈/身體/左手):
- AC-IoU parity:生成 mesh 覆蓋 IoU ≥ 藝術家 mesh IoU − 0.02。
- AC-topo:evaluate_mesh well-formed(0 退化/0 孤兒/質心全在遮罩)。
- AC-budget:生成頂點數 ≤ 藝術家頂點數。
- deform 閘 **N/A**:這 3 件在 Award 無 deform timeline(變形靠骨骼權重)。

### 過程與發現
1. 探測:3 件在 Award 為 **weighted mesh**(main_draw 4 mesh 為 unweighted)、**無 deform timeline**。
2. 驗證 uv 慣例:Spine mesh uvs 為 **region-local 正規化**;`extract()` derotate 後 `uv*(W,H)` 直接對應
   (direct IoU 0.97 vs v-flip 0.44–0.60 → direct 才對;旋轉件亦然)。
3. 首跑:光暈 parity FAIL(0.9316 vs 0.9795),身體/左手 PASS。
4. 診斷:①compare 工具初版把遮罩攤平純白 → Canny 內部取樣失效(只剩格點);②真因:固定
   `epsilon_frac=0.008` 對大平滑輪廓(光暈,藝術家用 78 全邊界點)取樣不足。epsilon 掃描確認到 0.002 才追平,
   但全域調低會爆 64 頂點預算。
5. 修:`generate_mesh` 加 **自適應邊界細化**(`target_iou`,由 epsilon ÷1.6 逐步降到覆蓋達標或超 vertex_cap;
   `target_iou=None` = 原行為,opt-in 無回歸)。`generate_mesh_v2` 透傳 `target_iou`。compare 工具改餵真實切件 RGB。
6. 重跑:**3 件全 PASS**(見下),overall exit 0。

### 結果(target_iou=0.97, margin=0.02)
| 件 | 藝術家 v/IoU | 生成(atlas) v/IoU/clean | 生成(PSD) v/IoU |
|---|---|---|---|
| 光暈 | 78 / 0.9795 | 67 / 0.9772 / ✓ | 64 / 0.9796 |
| 身體 | 98 / 0.976 | 68 / 0.9834 / ✓ | 67 / 0.9802 |
| 左手 | 80 / 0.9681 | 53 / 0.9755 / ✓ | 66 / 0.9737 |

→ 覆蓋追平/超越藝術家、頂點約 2/3、拓樸乾淨;atlas 與原生 PSD 兩來源皆過(尺度穩健)。

### 回歸驗證(無回歸)
