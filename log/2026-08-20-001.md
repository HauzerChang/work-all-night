## 3.8 資料坑(4 個都踩到)

過程中錯一次修一次,誠實記下:
1. **祖先動畫傳遞**:LBS 影響骨的祖先 `4_LEG2` 也被動畫化;只採 influence bones 會漏帶父動畫。
   → 修:`sample_times` 用 ancestor 聯集;`pose_at` 對「該 anim 有 keyframe 的所有 bone」都算。
2. **`transform=None`==normal**:JSON 欄位省略成 None;`d.get("transform")` 得到 None → NotImplemented raise。
   → 修:`d.get("transform","normal")`。**3.8 任何欄位都可能省略,default 是關鍵**。
3. **⚠️ Scale kf 缺欄 default 是 1,其他 channel 是 0**:第一版所有 default 都用 0.0 → LEG2 scale 塌成 0 →
   身體 mesh 塌成一個點(area=0)。SkeletonJson.readAnimation 對 scale x/y 用 `getFloat("x", 1)`,
   對 translate/shear 用 `getFloat("x", 0)`。 → 修:`_interp` 帶 per-channel defaults tuple。
4. **軟邊 halo 的藝術家實務容忍**:光暈 mesh 在自己動畫的 Legend_In 前段(t=0~0.37)有 71 SI + 7 flips +
   2x 面積 + 10x 邊拉伸 —— 藝術家對半透明加成效果的容忍(視覺不可見)。原 AC3 定義「藝術家 mesh 應全乾淨」
   過嚴 → 改為 baseline-recording(類比 `compare_robot_mesh` 的 IoU baseline)。**絕對 0 缺陷不是真理,
   ground-truth baseline 才是**。
