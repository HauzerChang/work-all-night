# 2026-09-08 session 003 — S1 wobble shear 峰隨檔位遞增(candidate G-4'')

## 目標(AC-first)

接續 STATE 建議 **(G-4'')**:補 G-4' 的 honest boundary —— G-4'(`gen_wobble`)是**第一個產 shear 通道的
生成器**,但 wobble ∉ `MAIN_SHOW_CATS` 且 `tier_variants.amplify_bone_tl` 不動 shear → **wobble 的 shear 峰
不隨檔位遞增**(各檔位共用同一斜拉幅度)。本次把 wobble 併入主秀、讓 `amplify_bone_tl` 也放大 shear，
使 shear 峰隨檔位遞增,而阻尼振盪簽章與 identity 介面對所有檔位保形。可檢查 AC = `validate_wobble_tier.py` 5 條
(present+backward-compat / crux shear 峰遞增==增益階梯 / 每檔位阻尼簽章保持 / identity 介面 / 平增益+隔離+阻尼比正交)。

## 做了什麼(全 additive,2 行語意)

1. **`tier_variants.MAIN_SHOW_CATS`** 加 `"wobble"` → `build_animations(tier_gains=)` 對 wobble beat 產
   `wobble__{tier}` 變體。
2. **`tier_variants.amplify_bone_tl`** 加 **shear 分支**:shear 繞 0(=identity)對稱擺動,故如 rotate/translate
   `v'=g·v`(x/y 皆乘;shearY 目前恆 0,乘 g 仍 0)。`g·0=0` 守零過零點→identity 介面;相繼極值同乘 g→阻尼比 r
   不變;base g=1.0 逐位元向後相容。
3. **`validate_wobble_tier.py`**(新)— 先驗庫→真實 build_spine robot 骨架→build_animations 整合閘,5 AC。
4. **`validate_tier_variants.py`**(J)J3/J4 改**通道感知**:因 wobble 併入 `MAIN_SHOW_CATS`,J 的 main_beats
   自動納入 wobble;原 J3 只量 scale overshoot/rotate 幅度(wobble 兩者皆無)→ 假陰性。改為對每 beat **實際存在**
   的通道(scale/rotate/shear)各要求嚴格遞增且 ≥1 通道存在(舊 scale-based beat 等價不減弱);J4 加 cat=="wobble"
   分支檢查阻尼 shear 簽章(復用 `validate_shear_gen` 判準)。
5. **`check_readiness`** 新增 cap `tier_variant_shear` L2 併入 `spine-anim-forge`;重生成 `skills/READINESS.md` 快照。
6. 圖 `knowledge/figures/s1_wobble_tier.png`(4 檔位 shearX 阻尼包絡疊圖 + 峰值==增益階梯 bar)。

## 決策 / 關鍵發現

- **shear 繞 0 擺動使對稱增益 `v'=g·v` 天生保形**:比 scale(繞 1、需「只放大 identity 上方 overshoot」的
  樓地板保護)更單純 —— shear 的過零點自動守住 identity 介面,阻尼比/變號數自動保持。shear 的幾何結構讓保形免費。
- **併入 `MAIN_SHOW_CATS` 會波及所有掃該集合的既有 milestone 閘**:J 的 main_beats 自動納入 wobble。**通道感知**
  (present-then-require:對存在的通道要求性質、缺席略過)是通用解 —— 對舊 beat 等價、對新 beat 正確,不減弱既有 crux。
- **正交性可量化**:阻尼比 r 跨檔位逐一相等(X5c)把「幅度軸 ⟂ 波形軸」從口號變成可驗負對照(同 (J) 樓地板不動 /
  (J-2) 連擊數正交於幅度)。
- **honest boundary 的價值再現**:G-4' 誠實標記「tier 變體未接 wobble」,本次照那條邊界接上,得到明確可驗收的下一步。
