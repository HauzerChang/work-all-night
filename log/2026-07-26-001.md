從 `STATE.md`「下一步動作」挑最高優先 bounded chunk:**PSD件/atlas → S3 mesh → 對照 Award 真實 mesh**
(有生產 ground truth、純 CPU 可自驅)。分支 `claude/vibrant-franklin-n1vpoq`。

### AC(先定,對真實標的可量測)
- E1 對齊自洽:藝術家 mesh 覆蓋 IoU ≥ 0.85(先確認我方量測對,否則修對映)。
- E2 生成覆蓋:gen IoU ≥ artist IoU − 0.03。
- E3 頂點預算:gen nv ≤ artist nv。
- E4 生成靜態品質:`evaluate_mesh` overall_pass。

### 實作 + 迭代
1. 新 `tools/mesh_gen/compare_award_mesh.py`:座標統一在 atlas region derotate 局部框
   (`atlas_crop.crop_region`,CW);生成 mesh 與藝術家 mesh 同框比 IoU/nv。
2. **迭代 1 — 對映錯誤(E1 抓到)**:先把 Award mesh `uvs` 當 atlas **page 正規化** → 落點跑出 region
   (身體 art_iou 0.0)。查:uvs 是 **region-local 正規化**([0,1] over 邏輯 w,h)。改 `u*W, v*H` 映到
   局部框 → E1 art_iou 0.98/0.97/0.98,對齊確認。
3. **迭代 2 — 光暈(soft/roundish)缺口**:光暈走舊 v2 fallback(散點 Delaunay)→ E2/E4 fail
   (孤兒頂點 1、IoU 0.929<藝術家 0.98)。依藝術家真值(光暈=78 頂點**全 hull**、無內部)在
   `generate_mesh_v2.py` 新增 **`contour` 模式**:`findContours`→二分搜 `approxPolyDP` epsilon 命中頂點預算
   →`triangle 'p'` 約束三角化簡單多邊形(尊重凹形、0 孤兒、不需重心過濾)。auto 路由:非 strip → contour
   (取代 delaunay-v1 fallback;strip 條件不變)。
