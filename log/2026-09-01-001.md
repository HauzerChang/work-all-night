# 2026-09-01 — session 001

## 目標(bounded chunk)

STATE 建議候選 **(B) mesh deform timeline 生成**:讓 `build --animate` 的 mesh 軟件(窗簾/陰影/布料)
會**逐頂點變形**,而非只被父骨剛體搬動(candidate 0d 只生 bone TRS + slot color 的缺口)。

## 做了什麼

1. **`tools/analyzer/gen_deform.py`(新)** — 對 skin 每個 **unweighted** mesh attachment 生成 Spine 3.8
   `deform` timeline。基元 = **駐波微顫**:位移(沿短軸)= `A·env(s)·sin(2π·k·s)·temporal(τ)`,
   `env(s)=(1-s)` 懸掛模型,`temporal` 在 τ=0/1 皆 0 → **deform 端點 == setup identity**
   → loop 無縫 + 與 gen_animations bone timeline 共用 identity 介面(對齊 0d AC4)。
   相容 3.8 list skin 與 build_spine `{name:atts}` dict skin;自動跳過 weighted mesh(deform 非其機制)。
2. **`gen_animations.build_animations` 加 `with_deform=True`** — build --animate 內建對軟件注入 deform。
3. **`tools/analyzer/validate_deform_gen.py`(新)** — AC 閘,主標的 = main_draw 4 真實藝術家 mesh。

## 決策 / 發現

- **此類 deform 對 strip 拓樸無條件安全**:純短軸橫向駐波施於直掛薄片,amp 拉到近真實 314px、
  wavenum 到 4.0,4 mesh 仍 si=0 → 正面穩健性,不是閘失能。故負對照改用扭轉壞場證鑑別力,
  而非拉爆生成器參數(誠實記錄於 knowledge)。
- **deform 只對 unweighted mesh**:weighted 靠骨骼 skinning,deform 非其機制且 setup 位置需 bind 逆變換。
- env/波數/擺幅屬美術先驗(A 類),客觀正確性交幾何閘。
