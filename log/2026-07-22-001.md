對照 Award spine 裡藝術家手做的真實 mesh。

1. **AC 定義**:每件 (a) 生成 mesh 覆蓋率 vs 件 alpha、(b) 藝術家 mesh 覆蓋率 vs 件 alpha,
   PASS ⇔ 生成 IoU ≥ 藝術家 IoU − 0.02 + 拓樸健全(對齊藝術家覆蓋,不用武斷閾值)。
2. **新工具** `tools/mesh_gen/compare_award_mesh.py`:psd_slice 切件 → generate_mesh_v2(auto) →
   evaluate_mesh 量 IoU → 對照 Award 真值 → 輸出 JSON + 覆蓋疊圖。
3. **抓修自身評估器 bug(關鍵)**:初版用藝術家 mesh 的 `vertices` 光柵化 → 藝術家 IoU 假性掉到
   0.48~0.62(荒謬:藝術家蓋不住自己貼圖)。查因:Award mesh `vertices` 在 bone-local 旋轉框
   (span/中心都不對齊 W/H)。改用 `uvs`(region-local upright)→ 回到 0.95~0.98。
4. **校準評估器**:對 atlas_crop CW 還原的 upright region alpha 測 6 種 uv 朝向,只有 plain 正確
   (0.97~0.98,其餘 0.40~0.70)→ 確認 uvs 就是 region-local upright,並**更正舊 caveat**
   「uvs 為 atlas UV 需轉 region」(其實不需)。
