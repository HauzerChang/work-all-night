# 2026-07-22 — session 001

## 這次做了什麼(S3+S4 端到端串通 — PSD件→mesh→對照 Award 真實 mesh)

接手時 STATE 的最高優先候選 1:用真實生產 mesh 當 ground truth,把 S3(mesh 生成)+ S4(PSD 切圖)
串成端到端並驗收。

1. **環境**:`pip install -r requirements.txt` OK(numpy 2.4.6 / cv2 5.0.0 / scipy / triangle / psd-tools)。
2. **分支釐清**:啟動所在分支 = `claude/vibrant-franklin-2l6cwv`(系統指定),與 `zealous-noether-y2ecwu`
   0/0 分歧(內容相同)。依系統指示 push 回 vibrant-franklin。
3. **切件**:`psd_slice.py assets/robot_parts.psd` → 5 件 PNG(光暈/右手/頭/身體/左手),重組閘 PASS。
4. **釐清資料**:查 Award.json,3 件為 mesh(光暈 78v/身體 98v/左手 80v);另查 uv range 發現
   **Award mesh uvs 其實是區域局部 0..1**(非舊 note 猜的 atlas UV)→ 既有 `artist_iou` 描點器可直接用。
5. **寫端到端比對器** `compare_award_mesh.py`:PSD件→`generate_mesh_v2`(auto)→ ① 生成 IoU(vs 切件 alpha)
   ② 藝術家基準 IoU(Award mesh 描到同一 mask)③ rest-pose 自交/翻面。
6. **抓修一個評估器坑**:`deform_eval.check` 的 `setup_signs` 需傳**布林 `area>0`**;傳 `np.sign`(-1/0/+1)
   會讓負面積三角恆判翻面 → 假性「全三角 flip」。修正後 rest flips 皆 0,self_intersections=0。
7. **結果:3 件全 `overall_pass`**。生成 mesh 用約半數頂點(35/60/59 vs 78/98/80)達 ≈/優於藝術家靜態覆蓋率
   (IoU 0.933/0.966/0.964 vs 0.949/0.948/0.977;身體超越)。
8. **視覺自驗**:`knowledge/figures/award_mesh_compare.png`(藝術家橘/生成綠疊在切件 alpha)確認朝向對齊、覆蓋相當。

## 關鍵結論 / 決策

- **auto 模式的長寬比+row-convex 閘剛好近似「deform-bearing(v2 strip)vs bone/weight-driven(v1)」分界**:
  這 3 件近方/寬且 Award 中無 deform timeline → auto 正確回退 v1,靜態覆蓋合適,不需 v2。
- **反向確認素材閉環(topology 層)**:藝術家 mesh(區域局部 uvs)描到 PSD 切件 alpha 就有 0.95~0.98 IoU
  → PSD 切件 = Award 素材、同朝向,補強 s4 的 alpha-IoU 閉環。
- **誠實邊界**:Award 這 3 件無 deform timeline → 未驗耐變形;本次只證「v1 對骨骼驅動件產出堪用靜態 mesh」,
  不推翻「deform 件需 v2」。
