# 2026-10-02 run 001 — S1 cascade 波方向一般化為任意角投影 (candidate J-6)

## 這次做了什麼(bounded chunk)

推進 STATE「下一步動作」明列的 **(J-6)** 候選:把 (J-5) 的 cascade 方向軸**由 4 向離散補成連續** ——
方向可給**角度(度)或向量 `(ux, uy)`**,相位依件中心在該單位向量上的**投影** `k = x·ux + y·uy` 排序。

## honest distinction(本次核心,勿誇大)

J-6 **不是**第四條正交軸。J-5 已把「方向 / 相位來源」立為跨件時序通道的**第三軸**(結構 nrip × 幅度 span × 方向)。
J-6 只是把這**同一條方向軸**的**取值**由「4 個具名」(lr/rl 基數軸 + co/oc radial)擴成「連續角 + 任意向量」;
機制仍是 J-5 的「既有相位的重新指派(排列)」,只改**排序鍵**:`{基數軸 ±x, radial}` → `{任意投影角, radial}`。

- **投影族含具名**:`lr`==θ=0°(`k=x`)、`rl`==θ=180°(`k=−x`)→ 基數軸是投影的特例(逐位元相容)。
- **投影族不含 co/oc**:radial(距中心)是 2D 非線性,任何單一投影都無法重現徑向序 → 保留為各自特例。
- **價值**:對角 / 垂直 / 任意角波,J-5 的 4 向表達不了(垂直 90°=`k=y` 在 robot 產波序件序 index `[3,0,4,1,2]`)。

## 鑑別(件序 ≠ 投影序的真實資產)

robot 件序 `[光暈,右手,頭,身體,左手]`,x/y 皆非單調 → 垂直(90°)波序 `[3,0,4,1,2]`、對角(45°)`[3,0,1,2,4]`
與全部 J-5 方向序 `{po [0,1,2,3,4], lr [1,0,2,3,4], rl [4,3,2,0,1], co [0,1,2,3,4], oc [4,3,2,1,0]}` **皆異**。
V5(a) 固化:垂直 / 對角的**實測峰序** ∉ J-5 件序集合 → 證任意角投影是真‧新方向,不是換名的具名方向。

## 關鍵發現

1. **離散→連續本身是通用槓桿**:凡是「挑了幾個具名值」的軸,問「這些具名是不是某連續參數的取樣?」往往能一般化
   (lr/rl 正是連續角 θ=0°/180° 的取樣)。J-5 把隱含預設顯式化成離散軸,J-6 再把離散軸補成連續。
2. **一般化要分清「含」與「不含」**:投影族含 lr/rl(基數軸=特例)但不含 co/oc(radial 另一族)。誠實的一般化要同時
   說清「哪些舊值被收編成特例」「哪些舊值是另一族、保留」。
3. **零回歸的來源是「特例逐位元相等」而非「預設不變」**:lr 的投影 `k=x·1+y·0` 浮點下精確 `=x`,與 J-5 直接 `k=x`
   逐位元相等。想宣稱向後相容要證舊值在新路徑下**逐位元**重現,不能只證預設沒變。
