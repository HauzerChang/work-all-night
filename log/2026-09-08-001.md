# 2026-09-08-001 — S1 件繞關節 pivot 一般仿射(非均勻 scale + shear,candidate G-4)

## 目標(本次 bounded chunk)

補 STATE 建議 **(G-4)**:把 0i(繞關節 pivot **轉**,M=R)/ G-3(繞 pivot **均勻縮放**,M=R·sI=相似變換)
推廣到**非均勻 scale(sx≠sy)與 shear** —— 此時 bone local M 是**一般仿射、不再是相似變換**。
驗證同一條補償公式 `Δ=(M−I)(O−P)` 仍讓關節 pivot P 精確不動,並為 shear/非均勻 scale 補上**仿射保形 AC**。

## AC(動手前定)

1. 非均勻 scale(sx≠sy)pivot 不動點殘差 < 0.5px + 負對照(繞件中心)明顯位移。
2. shear pivot 不動點殘差 < 0.5px + 負對照。
3. 仿射保形(關鍵幀)`world(x)−P == M·(x−P)` 精確(量化限內)。
4. **crux**:相似性「應該壞掉」——anisotropy(max|Md|−min|Md|)均勻 scale≈0、非均勻/ shear 顯著 >0。
5. identity 介面(首尾幀 Δ=0)。
6. 矩陣正確性:(a) shear=0 逐位元退化回 `transform_matrix`;(b) 真 Spine shear(det(pure shearX φ)=cosφ);
   (c) shear=None 仿射路徑 == G-3 srt 路徑。
7. 端到端 `apply_pivots(include_shear=True)`(rotate+scale+shear)有限/無縫/pivot 不動 + 內建負對照。

## 關鍵發現 / 踩雷

- **同一條 Δ=(M−I)(O−P) 貫穿 0i→G-3→G-4**,只差 M 的填法;不動點是純代數,和 M 是否相似無關。
- **相似 → 仿射,判準要換**:G-3 用等距-類比 `|w−P|=s|x−P|`;shear/非均勻 scale 下該概念不存在,硬套假陰性
  → 改驗更本質的仿射保形 `world−P=M(x−P)` + anisotropy 鑑別子。
- **真 Spine shear ≠ 天真 unit-shear**:`det(pure shearX φ)=cosφ`(改面積),用 det 鎖定實作。
- AC3 殘差是**關鍵幀量化**(角度/shear 存檔捨入 4dp,經件點偏移 ~350px 放大 ~4e-4px),非公式誤差。
- **honest boundary(生成器側)**:補齊的是幾何/公式 + 閘;`gen_animations` 尚未產 `shear` 通道
  → 「公式/閘就緒 ≠ 生成器接上」再現,惟管路已通(AC7),某節拍需 shear 時接上即可。
