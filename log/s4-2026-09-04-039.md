## 誠實限制

- 拆解功能的核心假設(生成式重繪+簡單分割能解決平圖拆件)完全未在真實素材/真實付費 API
  呼叫下驗證過,只驗證了分割演算法本身邏輯正確(給定一張乾淨版面能不能切開)。
- 切片分頁下載的單一圖層 PNG 不含 manifest 結構化資訊(offset/z/opacity),不能直接餵給
  既有 `atlas_crop.py` 等 Python pipeline 需要的格式,只是原始 PNG 檔。
- 需求精靈是規則表視覺化,不是使用者原話裡「收集需求做智慧規劃」的完整實現(那需要接 LLM
  推理做自然語言理解,是另一個量級的工作,本次明確未做,已在文件中誠實標註)。
- 仍未實作插件式像素對位管線(補圖/拆解的生成結果都可能有像素漂移)。
- API key 持久化 environment secret 只回答了操作方向(需使用者自己去 Claude Code on the
  web 的 environment 設定頁面),沒有工具能代為設定,也還沒有實際驗證使用者設定後排程
  session 能不能讀到。
