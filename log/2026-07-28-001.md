# 2026-07-28 — session 001

## 這次做了什麼(S3 端到端對照真實生產 mesh)

推進 STATE 最高優先 bounded chunk:**「PSD件 → S3 生成 mesh → 對照 Award 真實生產 mesh」**
(有 ground truth、純 CPU 可自驅)。

1. **新工具 `tools/mesh_gen/compare_award_mesh.py`**:對 Award 機器人 3 個 mesh 件(光暈/身體/左手)
   —— `atlas_crop.extract` 取 de-rotate 切件 alpha 當遮罩 → 藝術家 mesh 重組 IoU(baseline)
   vs `generate_mesh_v2` 生成 mesh IoU,同一像素框公平對照 + 格式/退化/孤兒自檢。
2. **驗證對齊正確**:Award mesh uvs 為 region-local(非全 atlas UV),藝術家重組 IoU 0.968–0.980
   反證對齊無誤(先前 knowledge 註的「atlas UV 需轉 region」其實 uvs 已是 region-local)。
3. **自我驗證迴圈揪出並修好 2 個生成器缺陷**:
   - 光暈(大面積細緻剪影)預設 eps=0.008 → IoU 0.93 落後生產 0.98 達 −0.05 + 孤兒頂點。
     加 `generate_adaptive`:以 **hull 覆蓋率**(免真值的自我指標)為目標由粗到細降 epsilon。
   - 身體:凹形三角過濾後遺留 1 內部孤兒。加 `prune_orphans`(只清內部、保 hull 順序)。
   - `generate_mesh_v2` 非 strip 分支改走 adaptive(`mode=delaunay-adaptive`)。
4. **結果 overall_pass=True**:3 件 IoU parity 全過(光暈 −0.0016 / 身體 −0.0074 / 左手 +0.0074),
   頂點更精簡(57–64 vs 藝術家 78–98),格式全乾淨。
5. **回歸**:main_draw 4 mesh 全走 strip,不受 delaunay 分支改動影響 → 重驗 4/4 IoU+deform 全過。

## 關鍵結論 / 決策

- **S4 切件 → S3 生成 → 生產真值對照** 端到端首次對「真實生產標的」驗收通過(先前只在 main_draw 自身)。
- 生成器兩處改進均為真值對照驅動、且**只影響 delaunay 分支**,零回歸風險。
- **誠實範圍**:Award 這 5 件無 deform timeline(骨骼權重變形)→ 本對照只驗**靜態覆蓋**,
  不含變形閘;變形穩健性仍由 main_draw 真實 deform 閘(strip)背書。生成 mesh 頂點較少屬靜態優勢,
  藝術家多的內部頂點多為權重 warp 用途,unweighted 靜態比對不涵蓋。
