# 2026-07-28 — session 001

## 這次做了什麼(S3 對真實生產標的:Award 機器人 weighted mesh)

推進 STATE 的最高優先 bounded chunk:**PSD件→S3 mesh→對照 Award 真實 mesh**。
但實作中發現真實標的的變形機制與 main_draw 不同,據此收斂為「靜態輪廓覆蓋」驗收 + 揭露 deform 閘缺口。

1. **枚舉 Award mesh**:7 個 mesh attachment 全 **weighted**;其中 3 個是機器人件
   (`機器人拆件/{左手,光暈,身體}`),region 分布在 Award.png / Award2.png(光暈/身體 rotate=true)。
2. **AC**:對每件從 atlas extract region alpha → 藝術家 weighted mesh 的 uvs+triangles 覆蓋 IoU = baseline
   → S3 生成 mesh 覆蓋 IoU 是否 ≥ baseline、頂點是否同級。**同一 region 像素空間,apples-to-apples。**
3. **掃參數自我驗證**:
   - strip(v2 預設)三件都**過不了**藝術家基準,rows 拉到 30(90v)封頂 ~0.95;cols 無影響(印證舊發現)。
     原因:三件皆**非 row-convex**,strip 每列填滿 min-x→max-x → 凹處過覆蓋。
   - `auto` 正確把這些件回退 **v1 Delaunay**(輪廓跟隨)。
   - v1 `epsilon_frac`:0.008 覆蓋不足;**0.002 三件全過**(0.9832~0.9926),nv 97~103 vs 藝術家 78~98。
4. **確認變形機制**:三件在 12 支動畫中 **0 條 deform timeline** → 純 bone-driven weighted。
   → `transfer_deform_check`(吃 per-vertex 位移場)**不適用**,本次不做 deform 閘(誠實標為缺口)。
5. **產出可重跑腳本 + 圖 + knowledge**。

## 關鍵結論 / 決策

- **S3 拓樸/覆蓋能力已對真實生產標的釘死**:v1 eps=0.002 在真實機器人件上達藝術家水準,頂點同級。
- **靜態≠變形穩健仍成立**:eps 越小靜態 IoU 越高,但正確取值取決於變形機制
  (deform-timeline 件別狂降 eps;bone-driven 件對密度較不敏感)。
- **揭露 S3 兩塊未建能力**:(a) BBW 權重綁定(生成 mesh→可 rig);(b) bone-driven 變形閘
  (weighted mesh × bone 動畫的自交/翻面)。這是端到端「PSD→件→可 rig mesh」最後兩哩。
- 未捏造 deform 結論:bone-driven deform 閘尚未建 → 本次只主張靜態層級。
