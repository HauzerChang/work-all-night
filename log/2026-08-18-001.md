## 關鍵結論 / 教訓

- **★ 更正舊筆記**:Award mesh 的 `uvs` 是 **region-local 0..1**(標準 Spine JSON 格式,runtime 再
  用 region atlas UV rect 重映),**不是** 先前 log/STATE 記的 atlas UV。實測 region-local 還原對切件
  IoU 0.95~0.98、座標吻合切件像素空間即證。以後讀寫 Award mesh / 組 Spine JSON 直接當 region-local。
- 三件近方形(aspect < 1.2)→ v2 auto **回退 v1 Delaunay**;strip 只吃高瘦 row-convex(窗簾)。
- 生成 mesh 更精簡(頂點 45–75% of 藝術家)覆蓋相當;身體/左手甚至略勝(藝術家凹處留白換變形自由)。
- 這 3 件在 Award **無 deform timeline**(weighted bone 變形)→ 不套 deform 轉移閘,只驗靜態覆蓋+格式(誠實標註)。
- 生成 mesh 為 **unweighted**;若要進 Award 需另配權重(S5/BBW,待建)。
