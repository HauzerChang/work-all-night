# 2026-06-28 — session 001

## 這次做了什麼(S3×S4 端到端:PSD 件 → 生成 mesh → 對照 Award 真實 mesh)

接 STATE.md 的最高優先 bounded chunk:把 S4(PSD 切件)接到 S3(mesh 生成),
對**真實生產 spine(Award)的機器人 mesh 件**端到端驗收。

1. **探查真實 mesh 結構**:Award.json 的 3 個機器人 mesh(光暈 78v/身體 98v/左手 80v)
   皆 **weighted(骨驅)**,且逐 anim 掃 `deform` 確認 **無 deform timeline** → 它們靠骨權重變形,
   不是逐頂點 deform。**因此正確的閘是「靜態覆蓋率 + 拓樸」,不是 main_draw 的 deform 轉移閘。**
   並更正交接誤解:Award mesh `uvs` 已是 region-local(0..1 填件),`artist_iou` 可直接比件 alpha。
2. **寫端到端對照工具** `tools/mesh_gen/compare_psd_to_award.py`:
   `psd_slice` 切件 alpha → `generate_mesh_v2` 生成 → `evaluate_mesh`(我的 IoU/拓樸)
   vs Award 藝術家 mesh 的 `artist_iou`(同一份件 alpha)。AC:① 拓樸乾淨 ② IoU parity ③ 頂點節約。
3. **結果:3 件全 `overall_pass`(exit 0)**:
   - 光暈:我 35v / IoU 0.933 vs 藝術家 78v / 0.949(parity ✓,頂點 0.45×)
   - 身體:我 60v / IoU **0.966** vs 藝術家 98v / 0.948(**IoU 更高**,頂點 0.61×)
   - 左手:我 59v / IoU 0.964 vs 藝術家 80v / 0.977(parity ✓,頂點 0.74×)
   - 三件拓樸全 clean(0 退化/0 孤兒/重心 100% 落 mask)。
4. **評估器負對照**:藝術家 mesh 對「錯件 mask」IoU 0.48–0.58 vs self 0.95–0.98(落差 ~0.4)
   → IoU 對形狀有強鑑別力,pass 判定可信。

## 關鍵結論

- **端到端鏈確立**:「PSD → 件 → S3 mesh」對真實生產標的通了,品質 ≥ 藝術家、頂點更省。
- **方法論收穫**:能力的閘要按「件如何變形」選 —— 骨驅件用靜態閘,逐頂點 deform 件才用 deform 轉移閘。
