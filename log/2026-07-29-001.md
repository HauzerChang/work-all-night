## 這次做了什麼(排程 session:端到端 PSD件 → S3 mesh → 對照 Award 真值)

推進 STATE 最高優先 bounded chunk:把 S4 切件與 S3 生成 mesh 接成端到端,並對**真實生產
mesh**(Award spine)做靜態覆蓋率驗收。

### AC(動手前定義)
- AC-slice:`psd_slice` 切出 robot_parts 的 3 mesh 件(光暈/身體/左手)alpha PNG。
- AC-format:生成 mesh 格式/預算/無孤兒/無退化(evaluate_mesh)。
- AC-iou:生成覆蓋率 IoU ≥ 藝術家自身基準 − 0.02(對齊藝術家,非武斷 0.95)。
- AC-agree:生成 mesh vs 藝術家 mesh 覆蓋一致性(診斷)。
- 評估器先驗:負對照確認 IoU 閘有鑑別力。

### 做法
1. `psd_slice.py` 切 robot_parts.psd → 5 件(取其中 3 個 Award 中為 mesh 的件)。
2. 新增 `tools/mesh_gen/validate_psd_to_award.py`:切件 alpha → `generate_mesh_v2(auto)` →
   ① evaluate_mesh 格式+覆蓋 ② Award 藝術家 mesh(uvs×遮罩尺寸)光柵化算基準 IoU
   ③ mesh↔mesh 覆蓋一致性。**尺度自動抵消**(兩邊都用 uv 分數 × 同一遮罩尺寸)。
3. 負對照:收縮頂點(向重心 ×0.85/×0.70)、錯 slot 疊圖。

## 關鍵結論

1. **首次把 S4(PSD 切件)→ S3(生成 mesh)串成端到端,對真實生產 mesh 驗收通過**(里程碑)。
2. **v2 auto 正確路由**:3 件近方(aspect<1.2)全走 v1 Delaunay;因 Award 這 3 件 weighted 且
   **無 deform timeline**,v1 deform-fragility 疑慮不適用,靜態覆蓋才是判準,v1 覆蓋佳且更精簡。
3. **Award mesh uvs 實測為 region-local 0..1** → 推翻 s4 筆記「需轉 region 局部」的過保守假設。
4. **deform 閘對 weighted/無 timeline 件明記 N/A**,不硬套未校準壓力(避免重蹈 stress_field 覆轍)。
5. **踩坑留痕**:`evaluate_mesh.AC1_iou` 讀 `vertices` 非 `uvs`;負對照要 corrupt 閘實際讀的欄位。
