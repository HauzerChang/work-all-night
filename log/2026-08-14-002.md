## 這次做了什麼(成果發表:以 Spine 動畫呈現研究成果,A/B 對照)

使用者要求「匯報研究成果,以 spine 動畫當發表;做 A(原始)/B(套研究成果最佳化)兩組,他用 Spine 預覽器對比」。

### AC(動手前定的可檢查目標)
B 必須:① 是**合法可載入**的 Spine 3.8 JSON;② **忠實重現 A 的動畫**(形狀對得上);
③ 展現研究帶來的**可量測改善**(平滑度);④ **不劣於 A**(0 自交/翻面);⑤ 只動網格、不動動作設計。

### 做法
把三個研究成果串成端到端最佳化 pipeline(`tools/demo/build_ab_demo.py`),對 main_draw 4 片會變形網格
(curtain_left/right, shadow, shadow2)升級:
1. **細分**:光柵化藝術家 mesh footprint → `gen_strip` 直條細分(21v/12v→64v/42v)。
2. **setup 重採樣**:RBF thin-plate 把原 setup local 當 uv 場重採樣到新格點。
3. **deform 轉移**:9 支動畫全部 deform 關鍵影格,位移場 RBF 平滑重採樣到新拓樸;time/curve 逐格原樣保留。
4. **幾何閘**:每幀 `deform_eval` 驗證,不乾淨退線性(保證不劣於 A)。

### 量化驗收(自動量測)
- 忠實度 shape IoU(B vs A,最大變形幀):0.985 / 0.986 / 0.974 / 0.958。
- 平滑度(邊界轉折角,9 動畫平均):curtain ~25°→~11°、shadow ~34°→~14°(↓54~59%)。
- 穩健度:全關鍵影格 A/B 皆 0 自交 / 0 翻面。
- 結構驗證:triangle 索引/hull/deform 陣列長度/有限值全過;bones28 slots40 anims9 與 A 一致。
- 視覺:`delivery/verify_ab_deform.png`(A 橘/B 綠線框對照)確認 B 貼合 A 且更平滑。

### 三個踩雷 & 修正(新學到,已寫進 knowledge)
1. 軟漸層 alpha 閾值化 → 網格變細(shadow IoU 0.45);改**光柵化 mesh footprint 當形狀源** → 0.97。
2. shadow2 是**非仿射 setup warp**(逐軸線性 14.7px、full 仿射 14.2px 殘差);改 **RBF thin-plate 重採樣 setup** → 0px。
3. deform 逐頂點綁死拓樸 → 換網格須逐格重建;全長 vertices + 保留 curve/time 即合法且時序不變。
