   timeline**(靠骨骼權重變形)→ **不套 deform 閘**(需 unweighted+deform),改用有真值可比的
   AC1 靜態覆蓋率 / AC2 setup 拓樸 / AC3 頂點預算(vs 藝術家)。
2. **寫端到端對照工具** `tools/mesh_gen/compare_award_mesh.py`:atlas 切件(自動選頁)→ generate_mesh_v2
   → 生成 IoU vs 藝術家 IoU vs 頂點數 vs setup 自交。
3. **第一輪**:身體/左手 PASS,**光暈 FAIL**(gen IoU 0.929 < 藝術家 0.979)。3 件非 strip → v2 回退
   Delaunay(v1)。查因:光暈柔邊圓形,固定 `epsilon_frac=0.008` 把圓弧簡化成 14-gon 內縮切角,少 ~5%。
4. **epsilon 掃描**(3 件):證實覆蓋率隨邊界密度單調上升(與 strip 的 rows 同槓桿),eps=0.002 三件皆
   IoU≥0.98 且頂點 ≤ 藝術家。
5. **修正 = 閉環自適應邊界細分**:`generate_mesh.generate(target_iou=, vertex_cap=)` epsilon 由粗到細取
   達標最粗值;`target_iou=None` 預設沿用固定 epsilon(向後相容)。v2 Delaunay 回退默認 `target_iou=0.98`。
6. **重跑**:3 件全 PASS(IoU 0.982–0.986 > 藝術家、頂點 57–73 < 藝術家 78–98、0 自交)。
7. **回歸**:main_draw 4 strip mesh 重驗仍全 overall_pass(strip 不走回退,不受影響)。

## 關鍵結論

- **S3 跨資產 + 跨 mesh 類型泛化**:從 main_draw(全 strip 柔性件)推廣到 Award(Delaunay 剛體/骨綁件),
  對真實生產 mesh 以藝術家真值驗收通過。

  閉環自適應,固定魔數對圓/柔邊件會系統性欠覆蓋。
