# 2026-07-13 — session 001

## 這次做了什麼(S3 端到端對照 Award 真實生產 mesh — 候選 1)

推進 STATE 的最高優先候選:PSD件 → `generate_mesh_v2` → 對照 Award 藝術家手做 mesh(有真值)。
Award(big win)裡機器人 3 件是藝術家 weighted mesh:`機器人拆件/{光暈,左手,身體}`。
把生成 mesh 與藝術家 mesh 放**同一張真實 alpha**(atlas 去旋轉切件)上比 IoU。

## AC(可檢查)
- 對 3 件:生成 mesh IoU ≥ 藝術家 mesh 自身覆蓋率 IoU − 0.03(以藝術家為基準,非武斷門檻)。
- 評估器可信:藝術家 mesh 對自身貼圖 IoU 必須 ≥ 0.90,否則拒絕出報告(sanity gate)。

## 結果(全部量化,非肉眼)
- **3/3 通過**:光暈 gen 0.966 vs artist 0.980;左手 0.982 vs 0.968;身體 0.986 vs 0.976。
  生成頂點 61/57/69 **< 藝術家 78/80/98** → 更精簡達同級覆蓋。
- **校正 log 006**:Award mesh uvs 是 **region 局部 0..1、y 向下**,非 atlas UV。
  佐證:直接 px=u*W,py=v*H(不翻 y)藝術家自身 IoU 0.97–0.98;翻 y 或當 atlas UV 皆得假低值。
  初版腳本正因採信舊假設,得到藝術家 IoU 0.0/0.49 的假基準 → sanity gate 擋下才發現。
- **修 v1 缺陷**:光暈初版 IoU 0.929。掃描證明 **IoU 由 hull 邊界密度(epsilon)決定,max_interior 零影響**
  (與 v2 strip「rows 決定、cols 不影響」同構)。`generate_mesh.py` 預設 epsilon 0.008→0.004,3 件全過。
- **回歸**:main_draw 4 mesh 走 v2 strip(mode=strip 確認),不受 epsilon 改動影響,重驗全 PASS。

## 決策
- 只比**靜態覆蓋率**:這 3 件是 weighted mesh(骨變形),deform 對照需重建骨骼權重變形場,超出本塊範圍 → 列為下一候選。
- epsilon 0.004 為新預設(而非更激進的 0.002):3 件全過且頂點仍 < 藝術家,不無謂增點。
