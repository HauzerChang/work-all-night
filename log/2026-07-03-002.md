## 這次做了什麼(一個工作天:PSD → 完整可載入 Spine 資產)

延續 session 001(PSD件→mesh→對照 Award)。使用者要求「一個工作天的產出」→ 推進 STATE 最高優先

### 子塊 A:SkelToJson(`tools/mesh_gen/skel_to_json.py`)
件(psd_slice)+ mesh/region spec → **完整 Spine 3.8 skeleton JSON**,setup pose == PSD 平面佈局。
- 固化真實慣例:slot 名 `<namespace>/<圖層名>`、一圖層⇄一 slot⇄一 attachment、mesh/region 分配。
- 座標:Spine y-up、原點 PSD 中心;bone 放件中心、rotation=0;unweighted mesh 頂點置中 → 落回原位。
- **4 AC 全過**(robot 5 件):
  1. 位置解析式 round-trip:重建 attachment **影像框**→轉 PSD px 比 offset/size → worst **0.0px**。
  2. 結構有效:slot→bone、skin→attachment、JSON 可序列化。
  3. mesh 格式閘:3 mesh 全過 evaluate_mesh。
  4. **光柵重建**:由 skeleton 位置(非 manifest)重合成 → 對 PSD composite premult-MAE **0.031**,
     輸出 PNG 視覺**完美還原機器人**(截圖確認)。

### 子塊 B:AtlasPack(`tools/mesh_gen/pack_atlas.py`)
件 → Spine/libgdx `.atlas` + 貼圖 sheet。shelf 打包、rotate:false、格式逐欄對齊真實 atlas。
- **驗收**:用**同一支** `atlas_crop.extract`(平時讀 Award/main_draw 真實 atlas 的碼)裁回每 region
  → 對源切件 **worst MAE = 0**(無損、可被標準工具讀回)。

### 整合
`robot.json`+`robot.atlas`+`robot.png` 三件齊;**JSON↔atlas 一致性**:5 attachment 全對到 region、
width/height==region size 全 match。⇒ `PSD →(S4 切件)→(S3 mesh)+ 組裝 + 打包 → 完整 Spine 資產`。

## 關鍵發現 / 決策 / 自我更正

  (mesh 是 alpha 輪廓形狀,本就 ≤ 矩形框)。改量影像框(bone±w/2,h/2,mesh 與 region 一致)→ 全 0px。
  又一次「評估器要對齊真正要量的東西」教訓。
- **誠實邊界(明列於 knowledge)**:①**未在 Spine runtime 實載**(CDN 擋、無 headless loader)→ 驗證止於
  結構/幾何/光柵;②setup rotation=0 平面佈局(Award 的 posed rotation/骨階層屬 S5 綁定);
  ③光柵重建用整件矩形驗位置(與 mesh 覆蓋率解耦;真 mesh 渲染邊緣覆蓋=S3 已量 IoU ~0.96)。
