## 這次做了什麼(S3+S4 端到端:PSD件→mesh→對照 Award 真實藝術家 mesh)

接續 STATE 最高優先 bounded chunk:把 S4(PSD 切圖)與 S3(mesh 生成)串成端到端,並對**真實生產
藝術家 mesh** 做量化對照(這是第一次有藝術家真值可比的 mesh 生成驗收)。

1. **定 AC(先於實作)**:同一件在同一張 Award attachment (W,H) 畫布上柵格化「我方 generate_mesh_v2
   自動 mesh」vs「藝術家手做 mesh」,對同一 GT(PSD 件 alpha)量輪廓覆蓋 IoU。
   PASS = `IoU_mine >= IoU_artist - 0.03` 且我方 mesh 靜態 evaluate 全過。
2. **前置探查**:Award 3 個 warp 件(光暈/左手/身體)是 **weighted mesh**(78/80/98 頂點);
   實測 uvs 要 `py=v*H`(不翻)才對齊件 alpha(翻了 IoU 崩到 0.43~0.61)。PSD 件尺寸 ⇄ attachment 差 +2px(padding)確認。
3. **實作 `tools/mesh_gen/compare_award_mesh.py`** 並跑 3 件:**overall_pass: true**
   - 光暈 IoU 0.933 vs 藝術家 0.946(gap −0.013)、35v vs 78v
   - 左手 IoU 0.964 vs 0.965(gap −0.001)、59v vs 80v
   - 身體 IoU **0.966 vs 0.946(勝 +0.020)**、60v vs 98v
   - 3 件 auto 都落 **delaunay-v1**(非窗簾型,auto 正確不選 strip);頂點平均少 ~40%。
4. **抓修門檻不一致假性失敗**:首版用 `alpha>10` 當評估 mask、但工具內部 `>8` → 身體 1/97 邊界三角
   讓 AC2a 掉到 98.97% 假性 fail。改用 `em.load_mask`(>8)一致後全過。**第 4 次「評估器校準」類 bug**
   (前:stress_field、composite 白底、atlas derotate 方向)。
5. **負對照(可信度)**:身體 GT vs 自身藝術家 mesh 0.946、換左手 mesh 0.513、平移 80px 0.312 → 鑑別 gap>0.3 OK。

## 關鍵結論 / 教訓

- **S3+S4 端到端對真實藝術家真值驗收通過**(里程碑):自動 mesh 輪廓覆蓋不輸藝術家,且更省頂點。
- **範圍誠實**:這 3 件在 Award **無 deform timeline**(靠骨骼 warp),本次**只驗靜態覆蓋 + 頂點經濟,
  未驗 warp 手感**——後者需把 mesh 綁 Award 骨架權重才可比。
- **GT mask 定義要跨生成/評估一致**:差 1~2 灰階就在邊界三角翻判 AC2a(再次印證 RULES「閘要校準」)。
- uvs 翻轉快篩:對齊件 alpha 用 `py=v*H`;翻了 IoU 崩 → 可當方向健檢。
