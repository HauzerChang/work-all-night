# 2026-08-12 — session 001

## 這次做了什麼(S3 端到端對照 Award 真實生產 mesh)

接續 STATE 最高優先 chunk:「PSD件 → S3 mesh → 對照 Award 真實 mesh(有真值、純 CPU)」。

1. **定位真值**:Award.json slot `機器人拆件/{光暈,身體,左手}` 為 mesh、**weighted、無 deform
   timeline**(靠骨骼驅動);右手/頭為 region。→ 對照為**靜態覆蓋 + 頂點預算**,deform 閘 N/A。
2. **建 harness**:`tools/mesh_gen/compare_award_mesh.py` — atlas_crop 取真值 region(多頁+rotate)當遮罩
   → `generate_mesh_v2` auto 產 mesh → 對 `artist_iou`(藝術家 mesh 覆蓋)+ 頂點數 + 幾何健康。
3. **首跑發現差距**:預設下 3 件覆蓋 IoU 0.929/0.968/0.960,**略低於**藝術家 0.980/0.976/0.968;
   auto 正確選 delaunay 路徑(件為團塊非高瘦條)。
4. **掃描定因**:epsilon × 內部密度掃描 → **覆蓋 IoU 由 `epsilon_frac`(邊界取樣密度)單調決定,
   內部點(min_dist/max_interior)對覆蓋率無影響**(把 strip 的「rows 定覆蓋」定律推廣到 delaunay)。
5. **修正**:delaunay 分支預設 epsilon 0.008→0.002(加 `delaunay_epsilon` 參數)。三件覆蓋 IoU
   →0.983/0.993/0.991,**全 ≥ 藝術家**,頂點數 73/77/67(< 藝術家 78/98/80)、0 孤兒。
6. **評估器校準(第 4 次)**:`evaluate_mesh` 絕對 `vertex_budget=64` 比真實生產(78/98/80)還嚴,
   連藝術家都會 fail → 對照真值改以藝術家頂點數為參照 + 另判 `mine ≤ artist`。
7. **回歸驗證**:main_draw 4 mesh 走 strip 路徑,不受 delaunay 預設變更影響 → v2 驗證全過。
8. **視覺確認**:`knowledge/figures/award_mesh_{glow,body,lefthand}.png`(藝術家橘 vs 本工具綠疊 alpha)。

## 關鍵結論

- **端到端里程碑**:S3 生成 mesh 對真實生產 mesh **覆蓋不輸、頂點更省、幾何乾淨**。第一次對外部真值驗收。
- **覆蓋率定律通用**:覆蓋率靠**邊界取樣密度**(delaunay=epsilon / strip=rows);**內部點是給變形平滑度的**。
- **絕對閾值換標的要重校**:合成期的 vertex_budget=64 在真實生產下失準 → 延續 RULES「閘先校準」。
