## 關鍵發現 / 決策

- **Award mesh 是 weighted,但 `uvs` 是 region 局部正規化** → 不必解 weighted 頂點,直接 `px=u*W` 就能
  取藝術家覆蓋當幾何真值。這是本次能對照的關鍵技術點。

  → 本次驗**靜態覆蓋+精簡度**,耐變形不在此驗(窗簾 4-mesh 已驗)。
- 我方 mesh **更精簡**(頂點約藝術家一半)且覆蓋相當,身體甚至更貼 alpha 邊界 → S3 生成品質對真實件達標。
