# 2026-08-02 — session 001

## 這次做了什麼(S3 端到端:PSD 件 → 自產 mesh → 對照真實生產 mesh)

接續 STATE / log 005·006 的最高優先「下一步」:用機器人 PSD 件跑 S3,對照 `Award.json`
真實 mesh 做 ground-truth 驗收(有真值、純 CPU 可自驅)。

1. **切件**:`psd_slice.py assets/robot_parts.psd` → 5 件 PNG(光暈/右手/頭/身體/左手)。
   3 個 mesh 件 size 與 Award attachment width/height 差 2px(padding),確認同框可比。
2. **自產 mesh**:`generate_mesh_v2` 對 3 件 → 皆 auto 回退 **delaunay-v1**(blob 非 row-convex)。
3. **新工具 `compare_to_real_mesh.py`**:把真實 mesh 的 uv 三角形柵格化到件像素畫布求覆蓋 IoU
   =藝術家基準;自產 mesh 用 evaluate_mesh 對同 alpha 求 IoU;同框比較 + 頂點數。
4. **結果 OVERALL PASS**:

   | slot | 自產 v / IoU | 藝術家 v / IoU | Δ |
   |---|---|---|---|
   | 光暈 | 35 / 0.9331 | 78 / 0.9487 | −0.0156 |
   | 身體 | 60 / 0.9660 | 98 / 0.9493 | +0.0167 |
   | 左手 | 59 / 0.9642 | 80 / 0.9808 | −0.0166 |

   自產覆蓋率與藝術家持平(±0.017),頂點少 40~55%,拓樸乾淨。
5. **負對照**:真實 mesh × 交叉件 alpha IoU 矩陣,對角 0.949/0.949/0.981、離對角 0.47~0.58
   (~0.4 落差)→ 覆蓋率閘有鑑別力,非僥倖。
6. **對齊約定確認**:真實 mesh uv→pixel 最佳方向皆 flip_y=False(spine uv v-down/左上原點)。

## 關鍵結論 / 教訓

- **S3 首次對外部藝術家真值驗收通過**(里程碑):先前只有自產 mesh vs 自身 alpha 的自證,
  這次證明自產 mesh 對真實生產標的覆蓋率達藝術家水準且更精簡。S4(切件)+S3(生 mesh)端到端串通。
- **限制留痕**:這 3 件是 weighted(骨骼驅動)、**無 deform timeline** → 無真實位移場可轉移,
  依 RULES 不用未校準 stress_field,故此處只驗**靜態覆蓋 + 拓樸**。耐變形能力已在 main_draw
  4 個有 deform 的 mesh 用真實位移場驗過(s3-four-mesh-generalization.md)。
