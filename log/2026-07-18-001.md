3 個機器人 warp mesh 件(`機器人拆件/{光暈,左手,身體}`,對應 robot_parts.psd 圖層)—— 做端到端驗收。

### AC(動手前定的可檢查目標)

- 對 3 件各自:生成 mesh 靜態 IoU(vs 該件 alpha)**≥ 藝術家手做 mesh 基準**(藝術家 uvs+tris 光柵化)。
- 頂點數 **≤ 藝術家頂點預算**(不靠灌點作弊)。
- 先驗評估器可信(藝術家基準 by-construction + 負對照鑑別)才下判定。

### 過程

1. 探查:3 warp 件在 Award 中為 **weighted mesh**(78/80/98 頂點),且**無 deform timeline**(靠骨骼權重動)。
2. atlas_crop 從 Award.png(雙頁)抽出 3 件 region(0.70 打包,496×480 / 181×152 / 267×299)。
3. 首跑 v2 auto → 全走 delaunay-v1 回退(aspect<1.2)。**IoU:光暈 0.929 / 左手 0.960 / 身體 0.968,均低於藝術家。**
4. 診斷光暈掉 5%:hull 只 14 點 vs 藝術家 78 點傳描;根因 = Douglas-Peucker `epsilon_frac=0.008` 對羽化邊過粗。
5. epsilon 掃描:**0.002 是甜蜜點** —— 三件 IoU 0.983/0.991/0.993 全 ≥ 藝術家,且頂點 73/67/77 仍 ≤ 藝術家預算。
6. 先驗評估器:藝術家基準由真實 uvs+tris 光柵化(ground truth);負對照 eps=0.05 → IoU 掉 0.61/0.77 → 有鑑別力。
