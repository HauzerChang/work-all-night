# 2026-09-25 run 001 — S1 (G-4''''''-vol) volume-conserving twist(反相雙軸 shear + 均勻體積守恆 scale)

## 這次做了什麼(bounded chunk)

延續 run(2026-09-24 001,G-4''''''-count)在 STATE 尾列出的候選 **(G-4''''''-vol)**:補上 twist(G-4'''''')
一路留到現在的 honest boundary —— **「反相雙軸未接體積守恆耦合 scale(`det=cos(shearX−shearY)≠1` → 擰轉變面積)」**。

**問題**:Spine local bone 的 2×2 行列式 `det(M) = scaleX·scaleY·cos(shearX − shearY)`(與 rotate 無關)。twist 令
scaleX=scaleY=1、shearY=−φ·shearX(φ=0.7)⇒ `det = cos((1+φ)·shearX) < 1`(body 峰 27.2° → det **0.889**,擰轉峰值
面積收縮 ~11%;head ~8.5%)。**解法**:對反相雙軸 shear 每幀施**均勻**體積守恆 scale `scaleX=scaleY=s=1/√cos(shearX−shearY)`
⇒ `det = s²·cos ≡ 1`(面積守恆)且**長寬比不變**;首尾 shearX=shearY=0 → s=1 → identity 介面保持。

## crux —— 為什麼 twist 用「均勻」、squash 用「非均勻」

| 節拍 | shear | 面積虧損 | 守恆 scale |
|---|---|---|---|
| squash(G-4'''') | 單軸 shearX | 想做**各向異性**擠壓 | **非均勻** scaleX=1+q、scaleY=1/(1+q) |
| **twistvol(本次)** | 反相雙軸 | `cos(shearX−shearY)` **各向同性**行列式虧損 | **均勻** scaleX=scaleY=1/√cos |

各向同性的行列式虧損補回它最乾淨的方式就是均勻放大兩軸(不引入 squash 的長寬比改變)。
**「守恆的 scale 型態由虧損的對稱性決定」**;至此**一般仿射四自由度(rotate/scale/shearX/shearY)可同時被生成器產且面積守恆**。
