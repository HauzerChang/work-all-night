# 2026-09-08 session 002 — S1 生成器產出 shear 通道端到端(candidate G-4')

## 目標(AC-first)

接續 STATE 建議 **(G-4')**:補 G-4 的 honest boundary —— G-4 補齊了「件繞關節 pivot 一般仿射(含 shear)」
的**公式 + 閘**,但當時**沒有任何 beat 生成器產出 shear 通道**(AC7 只用合成 shear 驗管路)。本次讓某節拍
**實際產出 shear 通道** + `build_spine` 帶 `include_shear=True` 端到端,把「公式/模板就緒 ≠ 生成器接上」
這最後一段接上。可檢查 AC = `validate_shear_gen.py` 5 條(present+shear 產出 crux / 阻尼振盪簽章 /
identity 介面 / 端到端 pivot 不動 / 負對照隔離)。

## 做了什麼

1. **`beat_templates.gen_wobble`** — 斜拉 jelly wobble,**第一個產 `shear` 通道的生成器**。純 shearX
   阻尼擺動(0→+A→−rA→+r²A→−r³A→0,r=0.5,role 峰 10–16°),首尾 identity;shearY≡0。
   加 `WOBBLE_KEYWORDS`、`DUR["wobble"]=0.8`。
2. **`gen_animations`** 註冊 `_DISPATCH["wobble"]=gen_wobble`、`_CAT_KEYWORDS` 置前。
3. **`genre_priors.slot_bigwin`** 加 `wobble` beat(PROPOSAL;`prior_beats_unused`,覆蓋率仍 1.0)→
   `build_spine --animate` 直出 wobble。
4. **`build_spine`** 加 `--shear-pivot`(`shear_pivot=True` → `apply_pivots(include_scale=True,
   include_shear=True)`,含 --scale-pivot 語意);summary 回報 `pivot_centers`(O)/`pivot_joints`(P)。
5. **`validate_shear_gen.py`**(新)— 先驗庫→真實 build_spine robot 骨架→build_animations 整合閘,5 AC。
6. **`check_readiness`** 新增 cap `shear_channel_generation` L2 併入 `spine-anim-forge`。
7. 圖 `knowledge/figures/s1_shear_gen.png`(wobble shearX 阻尼包絡 + 端到端 pivot 殘差 bar)。

## 產出 / 結果

- `validate_shear_gen.py` **OVERALL PASS**(W1–W5 全綠):W1 shear 峰 16°、5 bone 全帶 shear;
  W2 繞 0 變號 4 + 極值 [16,8,4,2] 嚴格遞減;W4 `--shear-pivot` pivot 殘差 右手 0.009 / 頭 0.004 /
  左手 0.013px vs 負對照 8–24px(arm 50–164px);W5 天真單調 shear 簽章 FALSE、shear 僅 wobble、加性零回歸。
- **回歸全綠**:validate_priors / priors_beats / more_beats / beat_templates / cascade /
  priors_combo_charge / priors_cascade / tier_variants / tier_combo_count / pivot_rotation /
  scale_pivot / shear_pivot / deform_gen / anim(+selftest);round-trip validate_build 對 `--shear-pivot`
  build overall_pass(premult MAE 0.031、setup 不變);check_readiness 全 caps GREEN、anim-forge 仍 HOLD。

## 決策 / 關鍵發現

- **阻尼簽章需「振盪 + 遞減」兩條件並立**:天真單調 shear(0→A→hold)有 shear 值但 0 變號、無遞減 →
  W5(a) 負對照證閘測的是**阻尼振盪**非「有 shear 通道即可」。
- **shear 隔離讓補償對象明確**:wobble 純 shear、其餘 beat 無 shear → `include_shear=True` 只補償 wobble
  的 shear bone,對既有節拍逐位元零回歸。
- **honest boundary 的價值再現**:G-4 誠實標記缺口,本次正好照那條邊界接上,得到明確可驗收的下一步。
