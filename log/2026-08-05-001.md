## 這次做了什麼(S3 端到端對照真實生產 mesh — 里程碑)

承接 STATE 的「最高優先」候選 #1:把 S3 mesh 生成器放到**另一份、未見過的生產資產**
(Award big win 機器人)上,對照美術實際手做的 weighted mesh,做端到端量化驗收。

1. **盤點標的**:Award.json 機器人拆件裡 3 個 mesh(光暈 78v/身體 98v/左手 80v);右手/頭是 region。
2. **座標對映(關鍵)**:發現 Award mesh 的 `uvs` 是 **region-local [0,1]**(非整頁),`width/height`=
   原始邏輯尺寸(比對 PSD bbox 三件全吻合)。用 **alpha 剪影外部真值**掃 8 種 flip/swap 組合校正,
   三件一致選中 `u0v0s0`(直對映 uv×crop)且明顯勝出;dilate=6px 時 hull ~100% 落剪影內 →
   確認對映正確(承接 006「自洽≠方向對」教訓,堅持用外部真值)。
3. **生成 + 比對**:對每件 atlas 還原 crop 跑 `generate_mesh_v2`(auto),量三指標:
   gen∩real hull IoU、gen 覆蓋剪影、real 覆蓋剪影。
4. **固化成工具**:寫 `tools/mesh_gen/compare_to_real_mesh.py`(含 gate + `map_inside` 對映健全度檢核)。
5. **產視覺對照圖**:`knowledge/figures/s3-vs-real-robot-hulls.png`(綠=美術 hull、橙=S3 hull、灰=剪影)。

## 關鍵結論 / 教訓

- **S3 泛化到真實標的**:生成 hull 與美術手做 hull IoU 0.91–0.955;覆蓋率落在美術 ~1–4% 內,
  且用少 30–40% 頂點。頂點差距非品質缺口(美術多頂點是為 bone 平滑變形,不是輪廓)。
- **`auto` 選型正確**:3 件 aspect<1.2(團塊),delaunay 全面優於 strip(再證 strip↔高瘦、delaunay↔團塊分工)。
