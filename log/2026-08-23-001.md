# 2026-08-23 — session 001

## 這次做了什麼(bounded chunk:S3 候選 2 — weighted mesh 骨綁權重)

補上 STATE 候選 2「weighted mesh 骨骼變形平滑度未驗」——此前 S3 只驗靜態 IoU 與 unweighted deform 拓樸。

### 產出工具
- `tools/mesh_gen/bone_weights.py`:
  - Spine FK(`local_mat`/`fk_world`/`fk_world_posed`,transformMode=normal)。
  - weighted-mesh 解析 + rest 世界座標還原(`[nBones,boneIdx,bindX,bindY,weight,...]` × 骨 world)。
  - **heat-diffusion 權重**(Pinocchio 式):`(L + M·diag(1/d²)) W = M·diag(1/d²) P`,
    cotangent Laplacian + lumped Voronoi mass + 最近骨段 one-hot。尺度不變(α=1 免調參)、
    **PoU 數學保證**、稀疏化(≤4 骨/頂點)。
  - LBS 蒙皮(`bind_local`/`skin_deform`)+ `emit_weighted_vertices`(寫回 Spine 格式)。
- `tools/mesh_gen/validate_bone_weights.py`:對 Award 3 mesh 件(光暈/左手/身體)5 條 AC。

### 結果(3 件全 PASS,exit 0)
- AC1 PoU 精確(max|Δ|<1e-8)、AC2 稀疏 ≤4 骨/頂點、AC3 平滑度不劣於美術。
- **AC4 變形穩健(核心)**:用 **Award 真實骨骼動畫**驅動 LBS,gen 權重 **0 自交/翻面/退化**,
  且不比美術差 —— 光暈 gen 0 vs 美術 35、身體 gen 0 vs 美術 6(gen 甚至比出貨美術更穩健)。
- AC5 鑑別力:硬最近骨 0/1 負對照在同一極端 sweep 必壞(8~13 artifacts)。

### 關鍵研究發現 / 自我更正
1. **美術權重 = rig 意圖,不是幾何最近骨**:左手 80 頂點美術全以骨 62 為主導(骨 66 僅 ≤0.38 次要
   blend),但幾何上 ~44 頂點最近骨 66。→ 第一版「逐值比對美術權重」是錯的閘(罰掉合法且更平滑的
   替代解,違反「別學沒有唯一解的美術決定」原則)。改為**量變形品質**(權重是為變形服務的)。
2. **運動源真相原則**(延續 deform_eval 的 stress_field 教訓):第一版合成「單骨獨轉 ±25°」過度嚴苛,
   連美術 mesh 都判自交(重演 miscalibration)。改用 **Award 真實 rotate timeline**(協同旋轉)作核心
   運動源;無真實骨旋轉的件(身體:LEG3 剛體根/LEG7-8 零長輔助)才退回合成 sweep。
3. skinning 經 setup 不變量驗證(zero-delta 蒙皮 == rest,0 artifacts)→ 管線可信。
