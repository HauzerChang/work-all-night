# 2026-07-24 — session 001

## 這次做了什麼(端到端 PSD件→S3 mesh→對照 Award 真值 + 生成器 adaptive epsilon)

推進 STATE 的最高優先 bounded chunk:用 `robot_parts.psd` 的 3 個 warp 件對照 Award 真實生產
mesh,把 S3(mesh 生成)+ S4(PSD 切圖)串成端到端閉環,並以**藝術家真值**驗收。

### AC(動手前定的可檢查目標)
對 光暈/身體/左手 3 件,各要:
1. `psd_slice` 切件 → `generate_mesh_v2(auto)` 生成 mesh 格式合法(hull-first、0 退化、0 孤兒)。
2. 生成 mesh 對其 alpha mask 的覆蓋 IoU **≥ 藝術家 mesh 覆蓋 − 0.02**(同幀比對,消除尺度)。
3. PSD 來源與 atlas 來源結果一致(印證 S4「同素材」前置)。

### 做法與結果
- 新增 `tools/mesh_gen/psd_to_mesh_vs_award.py`:A) atlas 來源同幀比對、B) PSD 來源自我保真;
  真值 = Award 藝術家 weighted mesh 覆蓋(`artist_coverage` 用 uvs,weighted 也適用)。
- **首跑 2/3 過,光暈 fail**(0.929 < 0.980):查出 v1 Douglas-Peucker `epsilon=0.008` 對平滑凸形
  切角、邊界取樣不足(+1 孤兒頂點)。sweep 證實 eps=0.002 → 0.983、78v、0 孤兒。
- **修法(固化)**:`generate_mesh.generate` 加 `adaptive=True`:沿 epsilon 階梯用 `self_iou`
  (生成器自評,對自身 mask)收斂到 target_iou=0.97 且頂點 ≤ cap。符合「確定性演算法 + 評估器把關」。
- **重跑:overall_pass=true**。光暈 0.9832/73v、身體 0.9858/69v、左手 0.9816/57v,
  皆 **超越藝術家覆蓋且頂點更少**;PSD 來源與 atlas 來源差 <0.004。
- **回歸檢查**:main_draw 4 mesh 走 strip 路徑,不受 v1 改動影響 → curtain_left/right + shadow
  仍 overall_pass(deform si=0/flips=0)。(shadow2 與 shadow 共用 region,屬既有測試慣例,非回歸。)

## 關鍵結論
- **S3×S4 端到端對真實生產標的驗收通過**(里程碑):PSD 件生成的 mesh,保真度不輸藝術家手做、頂點更省。
- **生成器新原則**:epsilon 該隨形狀曲率自適應;用 self_iou 讓生成器**自我收斂**,不必靠外部真值。
- **誠實限制**:這 3 件在 Award 無 deform timeline(weighted 靠骨骼),本次僅驗靜態輪廓;
  deform 穩健真值驗證仍以 main_draw 4 個 unweighted deform mesh 為準。
