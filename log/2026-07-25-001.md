## 這次做了什麼(S3×S4 端到端:PSD 件 → 生成 mesh → 對照 Award 真實藝術家 mesh)

推進 STATE 的最高優先 bounded chunk:用機器人 3 個 mesh 件(光暈/身體/左手,Award 生產 spine 中為 mesh)
把「PSD→件→S3 mesh」對**真實生產藝術家 mesh 真值**做端到端輪廓覆蓋率驗收。

1. **切件**:`psd_slice.py assets/robot_parts.psd` → `/tmp/robot_slices`(5 件)。
2. **抓修座標雷(evaluator 校準)**:初版用 mesh `vertices` 中心化正規化去比對 → 藝術家 mesh IoU
   假性低(0.47~0.62)。查因:`vertices` 是**骨骼局部座標**帶 setup 旋轉,`width/height` 非頂點包圍盒。
   改用 **region-local `uvs`**(`u*W,v*H`)映射到 `atlas_crop` 抽出的 region alpha → 藝術家自覆蓋率
   **0.968~0.980**、v-flip 負對照僅 **0.44~0.61** → 評估器方向正確、有鑑別力,**先校驗才下判定**。
3. **新工具 `tools/mesh_gen/compare_award_mesh.py`**:共同空間 = Award atlas region alpha;
   兩條路徑 gen_from_region(隔離 S3 品質)/ gen_from_psd(真實端到端,對 PSD 件自身 alpha 評)。
4. **epsilon 掃描 → 關鍵發現**:blob 件覆蓋率幾乎全由 **hull 密度(v1 `epsilon_frac`)** 決定;
   預設 0.008 對 blob 過粗(距藝術家 1~5%),**`eps=0.002` 3 件全達/超 parity 且頂點 ≤ 藝術家**。
   與 v2 strip「IoU 由 rows 決定、cols 不影響」同一規律。`generate_mesh_v2` 加 `v1_kw` 轉傳(未改全域預設)。
5. **跨源偽差釐清**:gen-from-PSD 改對 **atlas region** 評掉到 ~0.95 → 是 PSD↔atlas ~0.70 縮放/對位差
   (上季 alpha-IoU 0.92~0.99 上限),**非 mesh 品質**;確認 PSD-mesh 對**自身 PSD alpha** = 0.983/0.991/0.990。
   修正 AC:各 mesh 對自己來源輪廓評,不跨源雙重扣分。

## 關鍵結論

- **里程碑:S3 mesh 首次對真實生產藝術家 mesh 驗收通過** — 3 blob 件覆蓋率 3/3 達/超 parity,頂點 ≤ 藝術家。
  S3(mesh 生成)+ S4(切圖)端到端串通並量化達標。
- **blob 件覆蓋率 = hull 密度函數**(eps 0.008→0.002 達 parity);內部點影響甚微。
