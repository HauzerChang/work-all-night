# 2026-08-28-005 — S5 rig pivot 推斷器首個塊

## 本次做了什麼(bounded chunk)

推進 **S5「骨架半自動」**——路線圖 PLAN 稱之唯一卡死環節、RULES 把「pivot 放哪」列 A 類人類決策。
本塊不追求完美自動,而是把**主觀微調前的客觀部分**做成確定性 baseline + 可信真值閘。

產出:
- `tools/analyzer/infer_pivots.py` — 推斷器。輸入抽象 `{name: [world_poly,...]}`;
  rasterize → overlap graph(frac_of_smaller)→ 全幅特效層剔除 → **root=最大結構件、BFS 建樹** →
  **每關節 pivot = parent∩child overlap 區域世界形心**。
- `tools/analyzer/validate_pivots.py` — 對 Award 機器人真值閘 + 負對照(`--selftest`)。
  真值 = 子骨世界原點(Spine 中即關節 pivot):身體=4_LEG3、頭/左手/右手=4_LEG4/5/6。
  件 silhouette 全在同一 Spine 世界座標系取得(mesh=setup skinning 世界頂點;region=atlas alpha 輪廓經
  region attachment+骨變換置世界)→ **免跨座標對齊**,評估乾淨。
- `knowledge/s5-pivot-inference.md`、`knowledge/figures/s5_pivot_inference.png`。

軀幹對角線 495px。**4 AC 全 PASS**:AC1 階層(root=身體、3 肢皆掛身體、無假邊 頭-右手)、
AC2 精度(max 25.1 ≤ 10%×495)、AC3 勝 baseline(中位 18.6<67.4)、AC4 特效剔除(光暈判 effect)。
**負對照** `--selftest`(用子件形心當推斷):AC2/AC3 皆 FAIL → 閘有鑑別力。

## 關鍵決策 / 發現

1. **pivot 精度相依 silhouette 緊緻度**(最重要,可轉移):先用鬆散 region bounding-quad,
   右手 overlap 形心被拉向件中心 → 誤差 **132px**;換 atlas **真實 alpha 輪廓** → **25px**。
   → 推 pivot 必餵真實 alpha(mesh 頂點 / atlas/PSD alpha),不可餵 bbox。
2. **BFS 建樹 > 最大 overlap MST**:四肢間假交疊(大張右手貼圖蓋到頭,頭-右手 2994px >
   身體-頭 902px)會讓 MST 把頭誤掛右手;由軀幹 BFS 則三肢同層皆軀幹之子,假邊自然消解。
3. **特效層剔除**:光暈以 frac≈1.0 覆蓋全部其他件 → 標 effect 不納結構樹(對齊 build_meta 語意)。
