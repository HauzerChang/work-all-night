## crux / 關鍵發現

- **補償是主通道效應的反函數,故隨檔位「重算」而非「放大」**:面積縮放 `cos(g·(shearX−shearY))` 是 g 的非線性
  函數 → 補償 scale 必須從放大後 shear 重算,不能沿用「線性放大 identity 上方」的 `_amp_scale`(那正是 vol 一直只作用
  base twist 的 honest boundary)。與 squash 的耦合 amplify 同一道理(跨通道約束放大時沿約束流形走)。
- **從放大後 shear 重算(而非從舊 scale 值反推)**:兩者皆能守恆,但從舊 scale 反推 dφ 用的是未放大 shear 隱含的
  角度,與實際存下的 4-dec 放大後 shear 有獨立捨入 → det 殘差**隨 g 疊大**(Legend 6e-4);從放大後 shear 重算則與
  runtime 用的 shear 精確配對 → det 殘差**同 base 級**(≤1e-4,不隨 g 疊大),且 base shear 皆 4-dec 精確 → Super 逐位元同 base。
- **雙機制成立**:帶跨通道守恆約束的檔位軸已在 squash(非均勻)/ twist(等向)兩種體積守恆機制成立;檔位放大時守恆
  由「從放大後主通道重算補償」保證。
