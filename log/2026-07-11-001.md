推進 STATE「下一步」最高優先候選:對真實生產標的做端到端「PSD→件→mesh」驗收(有真值可比、純 CPU 自驅)。

1. **確認標的**:Award 中機器人 3 個 mesh 件 — 光暈(78v/hull78)、身體(98v/154t/hull40)、

4. **結果:3 件全 overall_pass**(見下表)。

## 關鍵結論 / 發現

- **auto mode 對真實 blob 件正確選 Delaunay-v1**(3 件 aspect 皆 < 1.2,非窗簾長條)→ mode-selector 在
  兩類形狀(strip 窗簾 / blob 件)都選對,v2 通用性再獲一筆真實驗證。
- **生成 mesh 更精簡卻覆蓋相當/更好**(身體生成 60v IoU 0.966 勝藝術家 98v 的 0.948)。
- **藝術家頂點多 ≠ 覆蓋率高,而是 weighted deform 的控制密度**:S3 目前只保證輪廓覆蓋;
  生成「適合骨骼權重 warp 的均勻控制網格」是另一課題(需 BBW),誠實列為能力邊界。
- 這 3 件無 deform timeline → 不做 deform 轉移閘(不適用),只驗拓樸有效性 + 覆蓋率。
