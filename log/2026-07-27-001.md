# 2026-07-27 — session 001

## 這次做了什麼(S3 對照 Award 真實生產 mesh + adaptive 邊界細化)

推進 STATE.md 最高優先 chunk:端到端「PSD 件 → S3 mesh → 對照 Award 真實生產 mesh」靜態驗收。

1. **定 AC + 建對照工具**:Award(機器人 big win 生產 spine)有 3 個真實 weighted mesh 部位
   `機器人拆件/{光暈,身體,左手}`。確認**三件皆無 deform timeline**(bone-driven weighted)→
   真實位移場閘 N/A;本輪聚焦**靜態幾何**(覆蓋率 IoU vs 藝術家基準 + evaluate_mesh 全靜態 AC)。
   寫 `tools/mesh_gen/compare_award_mesh.py`(從 Award atlas 切 region → 藝術家 IoU 基準 →
   `generate_mesh_v2` → 對照)。
2. **初測揪出光暈 FAIL**:光暈 IoU 0.929 < 基準 0.9595。根因 = `generate_mesh` v1 固定
   `epsilon_frac=0.008` 的 `approxPolyDP` 把**羽化/複雜邊界**簡化到只剩 14 hull 點 → 覆蓋率不及藝術家;
   身體/左手(緊實形)同 epsilon 已達標,只有複雜邊界受害。epsilon 掃描證實覆蓋率是邊界細節受限。
3. **修正 = adaptive 邊界細化**:`generate_mesh.generate(..., adaptive=True)` 由粗到細掃 epsilon,
   取最粗(頂點最省)且覆蓋率 ≥ 0.96 的解,受 vertex_budget(64)約束;`generate_mesh_v2` 的
   delaunay fallback 改用之。**預設路徑不變(向後相容)**。
4. **驗收 + 回歸**:3 件全 overall_pass(光暈 0.929→**0.9629**;身體 0.968;左手 0.960),且 **S3 頂點
   全少於藝術家**(60<78 / 61<98 / 48<80)。main_draw 4 mesh `validate_against_real --gen v2` 回歸全過
   (走 strip 模式,與 delaunay 改動正交)。視覺確認圖 `knowledge/figures/s3-award-mesh-compare.png`。

## 關鍵結論

- **S3 首次對照真實藝術家生產 mesh 通過**(里程碑):覆蓋率達/超藝術家且更省頂點 → S3+S4 端到端
  (PSD→件→mesh)對真實生產標的靜態成立。
- **固定 epsilon 無法同時服務簡單形與羽化/複雜邊界** → adaptive 細化(受頂點預算約束)是正解。
- **暴露最大缺口 = weighted 綁權重**:Award 真實件全 weighted、靠骨骼驅動(無 mesh deform);S3 只產
  unweighted → 缺 BBW 自動綁權重才能把生成 mesh 接上真實骨架、才能做 weighted-deform 對照。
