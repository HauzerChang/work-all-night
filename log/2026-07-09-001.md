## 關鍵發現

- **★ Award JSON mesh uvs 是邏輯 region-local(未旋轉、與 PSD 來源同向)**:8-方向窮舉 3 件全 `id`
  勝出且差距明顯(光暈 .949 vs 次佳 .705;身體 .948 vs .604;左手 .977 vs .763)。定論:atlas 的
  `rotate`/0.70 縮小只在**貼圖打包層**,由 atlas loader 處理,**不進 JSON uvs**。重建藝術家覆蓋
  直接 `uv*(W,H)` 即可。身體 uv_x 只到 0.759 是**藝術真的沒鋪滿 region**,非旋轉假象(我方反而覆蓋更緊)。
- **v1 Delaunay 對不規則有機形真實件仍達標**(strip 只適合窗簾式高瘦件)。
- overlay 圖(`knowledge/figures/psd_award_mesh/`)視覺確認:我方(綠)與藝術家(橙)同向套準同一輪廓。

## 範圍界定(誠實)

- 這 3 件是 **weighted mesh 且無 deform timeline** → 本比對是**靜態覆蓋率 + 拓樸**,不是 deform 穩健度。
- 覆蓋率 IoU 是靜態代理:藝術家 weighted 內部拓樸為骨骼變形調過,我方 unweighted 只保證輪廓貼合。
  「覆蓋追平」≠「變形手感追平」;後者需 weighted 生成(BBW)+ 有 deform 的標的。
