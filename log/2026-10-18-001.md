## 關鍵發現

1. **self-containment 的可信證法 = 把資產搬出 repo 實跑 + `__file__` provenance**。靜態 grep import 看不到各入口
   用 `sys.path.insert` + 平面 import 做的動態 wiring;唯有「複製 assets/ 到 repo 外、清 sys.path 的 repo 路徑、
   subprocess 跑生成 + 驗收」才真證「使用者端拿到的能動」,provenance(`__file__` 在 `_bundled/`)把「碰巧 repo 還在
   path 上」的假性通過擋掉。
2. **逐 byte 複製 + sha256 manifest = 漂移防護**。bundle 不改寫內容(只搬位置),未來若改了 repo `tools/` 卻忘 re-bundle,
   E1-1 立刻 FAIL 提示重建。
3. **bundle 優先但零回歸**靠兩件並存:repo 既有閘先 import repo 版(sys.modules 快取先到先贏)+ bundle 與 repo 逐 byte 相同。
