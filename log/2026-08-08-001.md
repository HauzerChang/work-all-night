# 2026-08-08 — session 001

## 這次做了什麼(S3 對 Award 真實 mesh 端到端驗收 + v1 hull 自校準)

推進 STATE 的最高優先 bounded chunk:**PSD件/Award → S3 mesh → 對照 Award 真實 mesh**
(第一次用「另一支生產 spine」的真實 mesh 當 ground truth,先前 4-mesh 驗收用 main_draw)。

1. **確認對照標的**:`Award.json` 的 `機器人拆件/{光暈,身體,左手}` 為 **weighted mesh**、
   **無 deform timeline**(骨骼權重驅動);`右手/頭` 為 region。alpha 來源用 Award atlas region
   (光暈/身體在 Award2.png、左手在 Award.png,前三者 rotate=true → `atlas_crop` CW derotate)。
2. **先驗評估器可信**:重建藝術家 mesh 自身覆蓋率(uvs×[W,H] 填三角 vs alpha)= 0.9795/0.9760/0.9681,
   三者一致 → frame 對齊(derotate 方向 + region-local uvs)正確、評估器可信,才據此判定生成 mesh。
3. **初判與發現**:v1 auto 預設(epsilon_frac=0.008)生成 mesh 覆蓋率**低於**藝術家基準
   (光暈 0.927 差最多、身體 0.968、左手 0.960 皆 fail)。epsilon 掃描確認:**覆蓋率由 hull 密度決定**,
   光暈這種大柔邊 radial glow 最吃 hull;eps=0.002 是與藝術家等值甜蜜點(全過、nv≈藝術家、不過細分)。
4. **修正(操作化發現)**:給 `generate_mesh.generate` 加**自校準 hull 密度** —— 以 `mesh_self_iou`
   (重建覆蓋率 vs 自身 alpha,無需外部真值)為閘,epsilon 從 0.008 減半至達 `target_iou=0.985`
   或 nv≥`vertex_cap=140`,最多 6 輪;`target_iou=None` 還原舊單發行為(向後相容)。
5. **驗收**:修後 3 件全過藝術家基準(光暈 0.9924/身體 0.9858/左手 0.9913),nv(92/69/67)≈ 藝術家
   (78/98/80),各件自校準停在不同 epsilon(hull 58/29/43,依柔硬度自適應)。
   **回歸**:main_draw 4 mesh 走 v2 strip、不受 v1 改動影響,`validate_against_real --gen v2` 全 overall_pass。

## 關鍵結論 / 決策

- **固定 epsilon 不通用**:大而柔邊的件需更密 hull;自校準(覆蓋率閘)比固定值穩健,且不過度細分。
- **評估器可信度先驗是流程一部分**(藝術家 self-IoU 一致 = 這次的「負對照/自一致性」關卡),沿用專案
  「先校準再判定」的教訓。
- **誠實限制**:這 3 件無 deform timeline → 只能做**靜態拓樸/覆蓋率**對照,無法跑真實 deform 轉移閘;
  deform 耐受度結論仍以 main_draw 4-mesh(有 deform)為準。weighted 綁定(骨權)本工具尚未生成。
