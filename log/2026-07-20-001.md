# 2026-07-20 — session 001

## 這次做了什麼(S3 端到端對照 Award 真實生產 mesh — 里程碑)

接續 STATE 最高優先候選:把「PSD 切件 → S3 mesh 生成」對**真實生產 mesh**(Award big win 機器人)
做端到端驗收,有 ground truth 可逐件比對。

1. **切件**:`psd_slice.py` 切 `robot_parts.psd` → 光暈/身體/左手原解析度 alpha PNG。
2. **對照工具**:寫 `tools/mesh_gen/compare_award_mesh.py`。關鍵洞察:**Award mesh 的 `uvs` 為
   region-local 0..1**(非 atlas-page;Spine runtime 再映射),故可 `uv*(W,H)` 疊回 PSD 切件重建
   藝術家覆蓋 → `artist_iou` 真值 baseline。自動偵測 v 翻轉(結果全 `flip_v=false`,幾何級對齊)。
3. **首輪結果**:3 件生成 IoU 接近藝術家但 2 件差 ~1.5%(光暈 -0.0155、左手 -0.0126)。
4. **迭代(在 5 輪預算內,2 輪收斂)**:
   - 掃 `epsilon_frac`×`max_interior` → **發現 IoU 純由 hull 密度(epsilon)決定,內部點數完全不影響
     覆蓋率**(與 v2 strip 的「rows 決定、cols 不影響」是同一原理,跨兩生成器家族一致)。
   - v1 預設 epsilon=0.008 為窗簾調的、對 blob 太粗 → `generate_mesh_v2` 的 **blob-fallback 改用
     `blob_epsilon=0.004` + `blob_interior=18`**(v1 自身 default 不動,保住 legacy 窗簾路徑)。
   - 光暈殘留 orphan(AC2c 不過)→ 加 `drop_orphans`(只丟內部孤兒,不破壞 hull-first 不變式)。
5. **最終**:3 件 **IoU 全達/超藝術家、靜態 AC 全過**,頂點省 40~60%(見下表)。main_draw 回歸全過。
