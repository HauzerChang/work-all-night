# 2026-07-20 — session 001

## 這次做了什麼(S3×S4 端到端:PSD件→mesh→對照 Award 真實 mesh)

推進 STATE 的最高優先 bounded chunk(候選 #1,有真值可比、純 CPU 可自驅):
把「PSD→切件→S3 `generate_mesh_v2`」串成端到端,對 Award 生產 spine 的 3 個真實 mesh 件驗收。

### AC(動手前定的可量測目標)
1. 藝術家 mesh 對 alpha 覆蓋 IoU 應高(驗證評估器/重建可信,當基準線)。
2. 生成 mesh 覆蓋 IoU ≥ 藝術家基準線(或差距在小容差內)。
3. 生成 vs 藝術家 mesh 互相 IoU 高(覆蓋同一形狀)。
4. 報告頂點經濟度。

### 步驟
1. `psd_slice.py` 切 `robot_parts.psd` → 5 件 PNG(光暈/右手/頭/身體/左手)。
2. 對 3 個 mesh 件(光暈/身體/左手)跑 `generate_mesh_v2`。
3. 從 Award.json 的 region-local UV+triangles 還原「藝術家 mesh」到件-局部像素空間(Y 向兩種都試,取覆蓋高者)。
4. 量化覆蓋 IoU、互相 IoU、頂點比;寫成可重現工具 `tools/mesh_gen/compare_award_mesh.py`。

## 量化結果(全部 AC 通過)

| 件 | 藝術家 cover-IoU | 生成 cover-IoU | 互相 IoU | 頂點比(生成/藝術家) |
|---|---|---|---|---|
| 光暈 | 0.949 | 0.933 | 0.918 | 35/78 = 0.45 |
| 身體 | 0.948 | **0.966** ↑ | 0.928 | 60/98 = 0.61 |
| 左手 | 0.977 | 0.964 | 0.957 | 59/80 = 0.74 |

## 關鍵結論 / 教訓

- **端到端閉環成立**:PSD 切件 alpha ⇄ 生成 mesh ⇄ 藝術家生產 mesh 三者覆蓋一致(±1.6% 內,身體更高),
  且生成僅用 45–74% 頂點 → S3+S4 對真實生產標的驗收(里程碑)。
- **v1 vs v2 分工釐清**:3 件全走 `delaunay-v1`(aspect 0.84–1.12 < 1.2、非直條)→ v2 auto **正確回退**。
  blobby 角色件用 v1 散點即達生產覆蓋;strip 專為窗簾類高瘦逐頂點 deform 件。
- **評估器先驗可信**:藝術家基準 0.95 高;Y 向 flip=False 決定性勝(0.95 vs 0.43–0.60)→ 重建無歧義。
- **⚠️ 誠實限制**:只驗「靜態覆蓋 economy」。藝術家多出的頂點部分為 weighted 骨骼變形控制密度;
  這 5 件在 Award 為 weighted mesh 且**無 deform timeline**,無真實位移場可轉移 → deform 閘不適用,
  **weighted 骨骼變形品質未驗**(需另建骨骼綁定/skinning 閘)。
