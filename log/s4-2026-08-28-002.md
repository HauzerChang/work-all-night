# 2026-08-28 — S4 session 002(使用者直接指定:圖片預覽器)

## 這次做了什麼

使用者要求:「建立 PSD 圖片預覽器,讓切圖/補圖能力能即時預覽成果」。

### 1. 新增 `tools/mesh_gen/psd_preview.html`

單檔瀏覽器工具(vanilla JS + canvas,無外部依賴,風格比照 `spine_inspector.html`)。兩分頁,
依載入的 `manifest.json` 內容自動判斷模式:

- **切圖分頁**:載入 `psd_slice.py -o` 輸出資料夾 → 圖層清單(縮圖/z/offset/opacity/顯示開關)
  + 即時「重組」canvas(依 offset+z+opacity 疊圖)+ 若有參照 `composite.png` 則多顯示差異熱圖+MAE。
- **補圖分頁**:載入 `inpaint_eval.py -o` 輸出資料夾 → 校準狀態 chip + 案例選擇 + 8 格卡片
  (真值/破洞/正對照/2 負對照/3 baseline)並排比對(pass/fail 色點+四指標)+ 點圖開大圖看對 original
  的差異熱圖。

### 2. Python 端配合修改(向後相容,純新增欄位)

- `psd_slice.py`:`slice_psd(..., out_dir=...)` 額外存 `composite.png` + manifest 多 `"composite"` 欄位。
- `inpaint_eval.py`:`run_one()` 額外存「原圖」「破洞」PNG,每個方法分數多 `"file"` 欄位;`-o` 給定時
  額外寫 `manifest.json`。

### 3. 驗證(Playwright + headless Chromium,`/opt/pw-browsers` + 全域 `playwright` npm 套件)

- 切圖:重組 vs 參照 composite pixel-perfect(diff MAE 0.02/255);關掉一層 → 重組正確露出破洞、
  差異熱圖精準框出該層輪廓(MAE 8.23)。
- 補圖:8 卡正確渲染,pass/fail 與 `inpaint_eval.py` JSON 逐項吻合;modal 差異熱圖精準框出洞的範圍,
  視覺直接呈現「L1/L2 baseline 在機械紋理區補出模糊補丁」的既有結論。
- **踩到一個環境限定 caveat(已查清、與工具無關)**:Playwright `setInputFiles` 對中文檔名檔案在本
  容器會靜默丟棄(最小 repro 空白頁 `<input type=file>` 也重現),改用 `DataTransfer`+`new File()`
  模擬原生拖放後正確保留中文檔名並全數通過測試。記錄進 `knowledge/s4-preview-tool.md`,供之後想用
  Playwright 自動化測本工具的 session 參考,省得重踩。

### 4. 回歸測試

`build_spine.py` + `validate_build.py` 對 `robot_parts.psd` 重跑:`overall_pass: true`,確認
`psd_slice.py` 的 composite.png 新增不影響既有下游 pipeline(`build_spine.py`/`analyze_target.py`/
`validate_build.py`/`validate_flat_recall.py` 皆只用 `parts` list,不受 manifest 新增欄位影響)。
