推進 STATE 的最高優先候選:把 S4(PSD 切件)與 S3(mesh 生成)串成端到端,
並第一次對**真實生產 spine 的 weighted mesh**(Award 機器人 3 件)以藝術家 mesh 為外部真值
驗收覆蓋率。純 CPU、可自驅。

### AC(先定可檢查目標)
對機器人 3 件(光暈/左手/身體,在 Award 都是 mesh):
1. PSD 路徑:`robot_parts.psd` 圖層 alpha → `generate_mesh_v2(auto)` 產物合法
   (unweighted/hull-first/0 孤兒/0 退化/索引合法)。
2. 真值對照:同部位 atlas region alpha 上,生成 mesh 覆蓋率 IoU ≥ 藝術家 mesh 覆蓋率 IoU − 0.03。
3. 記錄 auto 模式選了 strip 還是 delaunay。

### 過程
1. 建 `tools/mesh_gen/validate_psd_to_award_mesh.py`:兩條互補路徑(PSD 路徑 + atlas region 真值對照)。
2. 首跑:左手/身體 PASS,**光暈 FAIL**(生成 0.929 vs 藝術家 0.980)。3 件皆正確路由到 v1 Delaunay
   (aspect<1.2、非 row-convex,strip 對 blob 反而差)。
3. 診斷:掃 epsilon/max_interior → **覆蓋率 IoU 由 hull DP 容差(epsilon)決定,內部點密度幾乎不影響**。
   固定 `epsilon_frac=0.008` 對大而圓的光暈欠取樣 hull(周長長,絕對容差過粗)。
4. 修正:`generate_mesh.generate` 加 `auto_hull_target=0.97`(+`vertex_cap`)—— 由粗到細試多個 epsilon,
   取達覆蓋率目標的最少頂點拓樸,把生成綁到評估器 IoU。v2 的 delaunay 退回路徑自動受惠。
5. 重跑:**3/3 overall_pass**,生成覆蓋率 0.982–0.986 達/勝藝術家(0.968–0.980)且頂點更精簡(57–73 vs 78–98)。
6. 回歸驗:`main_draw` 4 mesh `validate_against_real --gen v2` 仍全 overall_pass(strip 不受影響)。

## 關鍵結論 / 決策
- **覆蓋率是 hull 主導的**:S3 靜態保真度由 hull 邊界取樣密度決定,不是內部點。固定周長比例 epsilon
  對「大而平滑」的件會系統性欠取樣 → 自適應精化(綁評估器)是對的解,且無需人工調參。
- **泛化成立**:S3 從窗簾/陰影(高瘦條)泛化到機器人 blob(近圓/團塊),對真實生產標的達到藝術家覆蓋水準。
- **端到端打通(靜態)**:PSD→件→mesh 純 CPU 全自動,對真實 spine mesh 有外部真值可驗。
