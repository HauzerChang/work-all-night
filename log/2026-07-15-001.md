# 2026-07-15 — session 001

## 這次做了什麼(S3 對照 Award 真實 mesh — 端到端里程碑)

推進 STATE 候選 #1(最高優先、有真值可比):把 S3 mesh 生成器對**真實生產標的**驗收。

1. **定位真值**:Award spine 機器人 5 件中,光暈 / 左手 / 身體為 **mesh**(右手、頭為 region)。
   確認這些 slot 在全部動畫**無 deform timeline**(藝術家 weighted 是供綁骨/自由變形,非時間軸驅動)
   → 本比對聚焦**靜態覆蓋率 + 拓樸精簡度 + 足跡一致性**。
2. **共同座標框**:寫 `tools/mesh_gen/compare_to_award.py`。用 `atlas_crop` 去旋轉裁 region(atlas ~0.70 打包,
   兩邊同一張 → IoU 尺度無關)。藝術家 `uvs` 為 **region-local 0..1**(AC-A 覆蓋率 0.97~0.98 實證映射正確);
   S3 直接對同一 region alpha 跑 `generate_mesh_v2`(auto,三件長寬比<1.2 全走 v1 Delaunay)。
3. **首跑**:2/3 過。光暈(軟輻射漸層,藝術家 78 全 hull)S3 只 0.9292,卡 AC-B 門檻(≈與藝術家 0.9795 差)。
4. **診斷 + 修**:epsilon 掃描證實**軟邊件覆蓋率由 hull 取樣密度(epsilon)決定、非內部點**
   (0.008→0.9292 / 0.004→0.966 / 0.002→0.983),與先前 strip「IoU 由 rows 決定」同構。
   → `generate_mesh.generate` 加**覆蓋率自我收斂**迴圈(用自帶 `coverage_iou` 調 epsilon 到 target=0.95)。
5. **重跑**:`overall_pass: True`。三件 S3 覆蓋率 0.9656/0.9602/0.968(vs 藝術家 0.9795/0.9681/0.976)、
   頂點 61/48/61(< 藝術家 78/80/98)、足跡 IoU 0.954/0.945/0.955 —— 覆蓋不遜、更精簡、足跡一致。
6. **回歸**:refine 只動 v1 分支;main_draw 4 mesh(strip)重驗 curtain_left/right/shadow IoU 0.9338/0.9335/0.9549、
   self_intersections=0,與改前一致 → 無回歸。

## 關鍵結論 / 教訓

- **S3 對真實生產 mesh 端到端驗收通過**:純覆蓋型件上 S3 拓樸效率佳(頂點少於藝術家卻同等覆蓋;
  藝術家多頂點推測是為 weighted 綁骨的變形自由度,非覆蓋需要)。
- **覆蓋率的槓桿是 hull 取樣密度**(epsilon / rows),不是內部點 —— Delaunay 與 strip 兩版一致的規律。
- **修法用生成器自帶評估器自我收斂**,落實「每能力必配評估器 → 自主迭代收斂」。
- round-trip / 自驗要搭外部真值:這次藝術家 mesh 就是外部真值,AC-A 同時驗證了 uv→pixel 座標映射。
