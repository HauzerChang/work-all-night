# 2026-07-15 — session 001

## 這次做了什麼(bounded chunk:S3 端到端對真實生產 mesh 驗收)

推進 STATE 的最高優先候選 #1:**PSD/atlas 件 → S3 自動 mesh → 對照 Award 真實生產 mesh**。

1. **查證資料結構**:Award「機器人拆件」5 件中,光暈/身體/左手為 **mesh**、右手/頭為 region。
   3 個 mesh 都是 **weighted 且在 12 支動畫全無 deform timeline**(靠 bone 權重變形)。
   → 對這批件有意義的 AC 是「**靜態覆蓋率**」,非 deform 耐受(我目前不產權重,weighted deform 無真值可比)。
   確認 Award mesh uvs 為 region-local 0..1(非 atlas-page),`artist_iou` 可直接用。
2. **新工具 `tools/mesh_gen/validate_award_mesh.py`**:atlas 切真實貼圖(多頁+CW derotate)→
   `generate_mesh_v2` auto → 靜態 IoU/合法性(`evaluate_mesh`)+ 藝術家覆蓋率基準(`artist_iou`)。
3. **自我驗證迴圈(命中 2 個問題,均在 5 輪內修好)**:
   - **光暈 fail(IoU 0.929 < 藝術家 0.980 + 孤兒頂點)**:sweep 證實覆蓋率由 hull 取樣密度(epsilon)
     決定;v1 預設 `epsilon_frac` **0.008→0.004**(圓潤軟邊件 14→22 點 hull,IoU→0.966)。
   - **身體 fail(頂點 69 > budget 64)**:64 是對 main_draw 小 mesh 校準的武斷值;真實大件藝術家自身
     即 78~98v。改 budget **對齊藝術家頂點數**(方法論同 IoU:武斷常數→藝術家基準)。
4. **結果:3 件全 overall_pass**。身體/左手覆蓋率**勝過手做**(0.986>0.976、0.982>0.968)且更精簡
   (69<98、57<80);光暈略低於手做但在 margin 內、更精簡(61<78)。
5. **回歸全過**:main_draw curtain_left(v1)、4 mesh(v2)、S2 切圖閘 全 exit 0(epsilon 改動安全)。
6. **視覺驗證**:`knowledge/figures/award-robot-mesh-overlay.png`(綠=藝術家、青=生成,兩者皆貼合 alpha)。
