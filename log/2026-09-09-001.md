## 決策 / 關鍵發現

- **`SA.sample` 不處理 shear** → wobble 幅度在 sample 下隱形(scale=1/rotate=0);(J) J3 原用 scale/rotate
  量幅度會對 wobble 得 [0,0,0,0] 誤判 FAIL。修法=J3 通道感知(只對活躍通道要求遞增),shear 峰直接讀關鍵幀。
- **shear 對 0 對稱用 `g*v` 非 scale 版 `1+g(v−1)`**:shear identity=0(非 1);誤用 scale 版會把 0 幀
  推成 `1−g` 破壞端點。對 0 對稱擺動通道(rotate/translate/shear)一律 `g*v`。
- **均勻放大保阻尼比**:所有極值同乘 g → 比值不變 → 「檔位改幅度不改形狀」成可量化閘(T5c),誠實地把
  「愈高愈爆」限縮在幅度、不偷改運動語意(與美感手感 A 類分離),同 (J) 的「只放大 overshoot 不動樓地板」。
- **加性 opt-in**:`tier_gains=None` 逐位元同舊;wobble 進 MAIN_SHOW_CATS 只在帶 tier_gains 時多產變體,
  base 全綠;與 (J)/(J-2) scale/rotate/combo 檔位變體正交共存。
