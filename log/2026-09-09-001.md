# 2026-09-09 session 001 — S6 軌跡分析／曲線編輯工具鏈（使用者指定新項目）

## 目標（AC-first）

使用者提供 `spine-motion-skill`（次級動態細節調整）並要求做一個**軌跡調整工具（HTML）**，
減少「產圖 → 提出修正 → 再產圖」的來回。五項需求：
①分析特定目標（如胸部）的運動軌跡 ②網頁展示圖表 ③圖表可編輯曲線（位移量／時間／加刪點）
④輸出軌跡供 spine-motion-skill 辨識 ⑤（進階，尚須試驗）從 viewer 直接編輯。

可檢查的 AC = `tools/motion/validate_motion_tools.py` A1–A8：
三分解可加性 / 無損 round-trip / 延後 L 幀 / 幅度縮放 / 負對照 / JS↔Python parity /
無頭瀏覽器端到端（**頁面預測 vs 實測**）/ viewer 橋接契約。

## 做了什麼

1. **`tools/motion/spine_world.py`** — 世界座標取樣器：沿父鏈算世界矩陣、`zero=` 支援**逐通道**歸零、
   `own_split()` 把追蹤點軌跡拆成 rigid / rotOwn / transOwn、極值 / Pearson / 循環互相關。
   曲線內插重用 `tools/analyzer/spine_anim._interp`（避免兩份取樣器各說各話）。
2. **`analyze_trajectory.py`** — Spine JSON → `traj.json`（取樣序列 + 量化 + 可編輯關鍵幀 + 可編輯性判定）
   與 skill 規範的對照表 CSV；追蹤點預設取該骨骼 slot 的 attachment 中心。
3. **`motion_spec.py`** — 旋鈕（延後 / 幅度，以震盪中心縮放）、迴圈邊界 de Casteljau 切分、
   3.8 緊湊 bezier 讀寫、取樣。
4. **`apply_motion_spec.py`** — spec → 新動畫寫回（世界位移 → local translate），**驗證未全過不寫檔**。
5. **`verify_motion.py`** — V1–V7 結構閘（skill 第 6 步清單）+ Q1–Q3 量化閘。
6. **`spine_trajectory_editor.html`** — 單檔零相依編輯器：世界 X/Y 雙面板、拖曳關鍵幀（吸附半幀、
   Shift/Alt/Ctrl 修飾）、雙擊加點 / Del 刪點、關鍵幀數值表、延後 / 幅度 / 各軸幅度 / 緩動 / 迴圈接縫旋鈕、
   即時量化（幅度前後、相關、相位、互補的代價）、匯出 motion spec / CSV / skill 交辦文字、
   拖放與 `?traj=`/`?skel=` 載入、viewer postMessage 橋接。
7. **`spine_inspector.html`** — 加 `getBoneTrajectory()`（官方 runtime 取世界軌跡）、
   `openTrajectoryEditor()`（iframe / popup 內嵌）、收 `spine-motion/preview` → 寫回 rawJson → rebuild。
8. **`validate_motion_tools.py`** + `js_core_probe.js` + `bridge_harness.html` + `shot_editor.py`。
9. 修 `tools/analyzer/spine_anim._interp` 對**真實匯出檔**的相容性：第一個 key 省略 `time`、
   curve 省略 `c2/c3/c4`（缺省 0/1/1）。readiness 全區塊回歸不變。

## 決策 / 發現

- **`own = actual − rigid` 不夠**：要拆 `actual = rigid + rotOwn + transOwn`；只有 `transOwn` 能
  無損寫回 translate。拿總量回寫會把 rotate 貢獻重複計入（round-trip 後 X 幅度剛好兩倍）。
- **追蹤點預設不能用骨骼原點**（rotate-only 配件原點不動 → 自身位移誤讀成 0）。
- **延後前要先移除 loop 尾端的重複 key**，否則取模撞幀、去重留下錯曲線。
- **負對照逼出真 bug**：V7 原以**新**動畫總長為準 → 檢查恆真；改以**原**總長為準。
- **parity 閘逼出真差異**：JS 曲線求值原本重用對齊 runtime 的 `bezierY`（1e-7 提早跳出），
  與 Python 純二分差 1e-6 → 統一演算法。

## 界線（誠實）

- 進階功能⑤只驗到 **postMessage 契約**：`spine_inspector.html` 需 spine-webgl CDN，本環境 403，
  「畫面真的動起來」要在使用者端確認（列為 S6-a）。
- 世界↔local **內插固有殘差** 0.12px（父體有 scale 動畫時），關鍵值換算本身精確。
- 只動 translate（rotate 已在 spec/套用器支援，UI 未接）；mesh/權重/deform/attachment 不碰。
