## 關鍵發現 / 校正

1. **Award JSON mesh `uvs` 是 region 局部正規化 [0,1]**(非 atlas page 正規化)。這 5 件是
   **weighted mesh**,`vertices` 是權重格式不能當座標,setup 形狀只能從 uvs 還原(`u*W, v*H`,
   v 原點在上,與 atlas rotate 無關)。實測 4 種翻轉,只有此式對 3 件 IoU 0.968–0.979。
   → 對「切圖→Spine JSON 回寫」意義重大:mesh uvs 直接放 region 局部 0..1 即可。
2. **生成與評分必須同一張遮罩**:初版在 PSD 件(0.70 縮放前)生成卻對 region 評分,
   PSD↔region 羽化差(alpha-IoU 0.92–0.99)注入 ~5% 假性 gap,誤讀為生成器弱點。改在 region alpha
   生成後 gap 收到 −0.008。**教訓:先確認比的是同一個東西,再判生成器好壞。**
3. **生成器特性**:預設 `epsilon_frac=0.008` 對大面積平滑近圓件(光暈 496×480)收成 14-gon 過粗;
   平滑曲線角點少 → approxPolyDP 收太狠。→ 下一步做「曲率/面積自適應 epsilon」。
