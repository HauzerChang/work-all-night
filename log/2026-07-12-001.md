## 這次做了什麼(S3×S4 端到端:PSD 件 → 生成 mesh → 對照 Award 藝術家真值)

延續 STATE「最高優先(有真值可比)」候選:把 `robot_parts.psd` 的 3 個 mesh 件
(光暈/身體/左手,在生產 spine `Award` 中為 weighted mesh)串成端到端閉環驗收。

1. **新增 `tools/mesh_gen/compare_to_award.py`**:
   - `psd_slice` 切件 → `generate_mesh_v2` 生成 → `evaluate_mesh` 量化。
   - 從 `Award.json` 取藝術家真值 mesh,用 region-normalized uvs 還原件像素座標 → 同度量 coverage IoU。
   - 總判定 = 「相對藝術家(IoU ≥ 藝術家 − tol)」＋「幾何乾淨」(拆開,不用絕對 0.95)。
2. **AC(可檢查)**:每件 ①幾何乾淨(0 退化/0 孤兒/重心全在內/格式合法/頂點≤64)
   ②coverage IoU ≥ 藝術家真值 − 2%。→ **3 件 overall_pass=True**。
3. **評估器可信度**:負對照(真值 mesh 疊到別件 alpha)對角 0.95–0.98 ≫ 非對角 0.48–0.58,度量有鑑別力。

## 關鍵結論

- **端到端閉環成立**:PSD → 件 → 我的 S3 mesh,對真實生產藝術家 mesh 達**藝術家等級覆蓋**,
  且頂點更精簡(少 21–43/件;身體件覆蓋反超)。S3+S4 正式串起來對真實標的驗收。
- **★ 第四次評估器校準(重要)**:絕對 0.95 IoU AC 是在 main_draw 窗簾(近似凸/直條)上校準,
  **對軟邊/羽化件(光暈)過嚴 —— 連藝術家真值 0.9486 都不過**。正確判準是「相對藝術家 + 幾何乾淨」,
  非絕對 IoU 地板。延續前三次校準教訓(stress_field / composite 白底 / atlas 方向)。
- **技術點**:Award json mesh `uvs` = region-normalized [0,1](非整張 sheet),`(u·W,v·H)` 直接還原件像素;
  v 向下與 generate_mesh 一致。3 件為 weighted、**無 deform timeline** → 無真實位移場可轉 → 不做 deform 閘
  (依 RULES 不冒用未校準 stress)。
