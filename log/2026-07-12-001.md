## 這次做了什麼(S3×S4 端到端:PSD 件 → 生成 mesh → 對照 Award 真實生產 mesh)

推進 STATE 的最高優先 bounded chunk:把「PSD→件→S3 mesh」接到真實生產標的上驗收。

1. **前置解析**:Award.json 三件(光暈/身體/左手)確認皆為 **weighted mesh**
   (光暈 78v 純 hull、身體 98v/154t/hull40、左手 80v/116t/hull42),且 **無 deform timeline**。
2. **校正既有假設(關鍵)**:s4 doc 記「Award mesh uvs 為 atlas UV」是錯的。實測 UV bbox 皆約 0..1,
   確認 **Spine JSON mesh `uvs` 是 region-local**。用 PSD 件框直接 `uv*(W,H)` 得藝術家覆蓋,
   對件 alpha IoU=0.95/0.95/0.98(無 flip),任一 flip 都掉到 0.4–0.76 → 框天然對齊、無需 atlas 轉換。
3. **端到端閘** `validate_psd_to_award.py`:psd_slice 切件 → `generate_mesh_v2` → 覆蓋率 IoU
   (vs 件 alpha、vs 藝術家覆蓋)+ 頂點預算 + 交叉件負對照 + 疊圖。
4. **結果 3 件 overall_pass=True**:生成覆蓋率均在藝術家 ±0.02 內(身體 0.966>0.948 更高),
   頂點省至 45–61%(35/60/59 vs 78/98/80)。負對照同件 0.92–0.96 vs 交叉件 0.48–0.58(gap>0.33)。
5. **疊圖** `knowledge/figures/psd_to_award_mesh.png`:綠(交集)為主、紅/藍僅細邊 → 目視確認吻合。
