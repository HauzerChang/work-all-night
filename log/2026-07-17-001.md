## 關鍵發現

- **epsilon(Douglas-Peucker)單調換「頂點↔覆蓋率」**;default 0.008 偏省頂點 → 3 件 IoU 全低於藝術家、還留孤兒。
  降 epsilon 細化 hull → IoU 單調升、孤兒歸零。與 S3 窗簾「IoU 由邊界取樣密度決定」一致。
- **v1(Delaunay)適用團塊件**(光暈/身體/左手非長條 → `mode=auto` 正確回退 v1);v2 strip 適用窗簾長條。auto 路由已能分流。
- **閘鑑別力(內建負對照)**:default 粗 epsilon 3 件全 `iou_ge_artist=false` → 只有 auto-tune 後才過 → pass 有意義。

## 誠實 / 範圍

- 本閘**只驗靜態輪廓保真 + 拓樸 + 頂點預算**。藝術家 3 件是 **weighted(骨骼權重變形,無 deform timeline)**;
  生成的是 **unweighted** → **不宣稱變形手感等價**。加權(BBW)是 S3 下一未攻子目標。
