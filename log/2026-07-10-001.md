## 這次做了什麼(S3×S4 端到端:PSD件→mesh→對照 Award 真值)

推進 STATE 最高優先 bounded chunk #1:把 S4 切圖與 S3 mesh 生成串成端到端,對真實生產標的
(Award 機器人 3 件 mesh)以藝術家 mesh 為真值做驗收。

1. **定 AC(可量測)**:每件 ① 生成 mesh 覆蓋 IoU ≥ 藝術家 mesh 同法覆蓋(baseline,margin 0)
   ② 生成頂點 ≤ 藝術家頂點 ③ 通過 `evaluate_mesh` 幾何全閘。
2. **探真值**:確認 Award slot `機器人拆件/{光暈,身體,左手}` 為 mesh(78/98/80v,皆 weighted),
   右手/頭為 region;PSD bbox = Award mesh dims −2px(padding 慣例吻合);3 件**無 deform timeline**。
3. **寫端到端驗收器** `tools/mesh_gen/validate_psd_to_award.py`:psd_slice 切件 → generate_mesh_v2
   生成 → 用 **uvs** 光柵化對比切件 alpha(藝術家 weighted 不能直讀 vertices;uvs 在 art 邏輯空間,
   即使 atlas rotate:true 也對齊 —— baseline 0.95~0.98 合理性反查空間正確)。
4. **首輪**:margin 0 時 2/3 差一點(光暈 −1.6pp、左手 −1.3pp);做 epsilon 掃描 → 發現
   **覆蓋率單調受 hull 密度(Douglas-Peucker epsilon)支配**(與 strip「IoU 由 rows」同構定律)。
5. **加評估器驅動自動精修** `generate_mesh_v2._refine_delaunay`(對應 RULES 5 輪預算):沿遞減 epsilon
   排程取「首個覆蓋達標且頂點 ≤ 預算」者,**不依賴藝術家真值**(可上生產)。
6. **收斂**:coverage 目標 0.98 → **3/3 overall_pass**,生成 mesh 以更少頂點達更高覆蓋
   (光暈 72v/0.988、身體 67v/0.980、左手 75v/0.985 vs 藝術家 78/98/80、0.949/0.948/0.977);
   全數通過幾何全閘(centroid 1.0 / 0 退化 / 0 孤兒)。

## 關鍵結論

- **S3×S4 端到端對真實生產標的靜態驗收通過**(里程碑):證明「PSD切件 → 自動生成 mesh」在真實
  機器人 3 件上達到 ≥ 藝術家水準的覆蓋,且頂點更省。
