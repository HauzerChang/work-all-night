# 2026-07-10 — session 001

## 這次做了什麼(端到端 PSD件 → S3 mesh → 對照 Award 真實藝術家 mesh)

推進 STATE 最高優先 bounded chunk:把 S4 切件與 S3 生成器串成端到端管線,對**真實生產標的**
(機器人 big win 的生產 spine `Award`)驗收生成 mesh 的覆蓋率。

1. **確認資料座標空間**:Award 3 mesh 件(光暈/身體/左手)的 uvs 為 region-local 0..1、
   width/height 為原始邏輯尺寸、皆 **weighted**(靠骨骼蒙皮,無 deform timeline)。
   光暈/身體 atlas `rotate=true` 但 JSON uvs 在上直邏輯空間。
2. **切件**:`psd_slice.py` 從 `robot_parts.psd` 切出 5 件(native、乾淨、上直)。
3. **新閘 `tools/mesh_gen/validate_against_award.py`**:PSD 件 alpha → `generate_mesh_v2`
   → 生成 IoU vs Award 藝術家 mesh 在同一遮罩上的覆蓋 IoU;PASS ⇔ 生成 ≥ 藝術家 − 0.02
   且靜態有效性全過。
4. **評估器可信度**(先校準再判定):三重負/平凡對照 — 全 bbox 矩形只得填充率(0.47–0.68)、
   藝術家 mesh 縮 15% 掉到 0.68–0.73,都遠低於 ~0.95 → IoU 有鑑別力,非因近似填滿 bbox 虛高。
