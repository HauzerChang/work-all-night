# 2026-07-10 — session 001

## 這次做了什麼(S3 端到端對 Award 真實 mesh 驗收)

推進 STATE.md 最高優先 bounded chunk:把 S3 生成 mesh 套到 **Award 生產 spine 的 3 個真實 mesh 件**
(機器人拆件/光暈、身體、左手),以 atlas 切出的真實 alpha 為輸入,對照藝術家真實 mesh 的 IoU 覆蓋率。

### AC(動手前定)
- 每件:生成 mesh 的靜態 IoU ≥ 藝術家真實 mesh 的 IoU baseline −0.02(margin)。
- deform 閘:視資料而定(下方發現其為 weighted mesh → N/A)。

### 做法
1. 新增 `tools/mesh_gen/validate_award_mesh.py`:atlas 多頁+CW derotate 切件 → `generate_mesh_v2(auto)`
   → 光柵化 IoU(vs 真實 alpha)+ 藝術家 mesh 同 mask IoU baseline → pass 判定 + overlay PNG 存證。
2. 先跑一輪 → 光暈 FAIL(gen 0.929 vs 藝術家 0.980,gap −0.050)。

### 發現與修正(iteration budget 內,2 輪收斂)
- **發現 1**:3 件皆 **weighted mesh**(vertices≠uvs×2)且 **0 個 deform timeline** →
  變形靠骨骼權重,非逐頂點 deform。故 deform-transfer 閘 **N/A**(無位移場可轉);
  不套未校準合成壓力(避免重蹈 stress_field miscalibration)。AC 收斂在靜態覆蓋率。
- **發現 2**:光暈是大柔邊發光件,藝術家用 78 純 hull 點描邊;v1 固定 `epsilon=0.008` 把 hull
  塌成 14 點 → 丟覆蓋率。epsilon 掃描證實**覆蓋率隨邊界密度單調上升**(同 v2 strip「IoU 由 rows 決定」)。
- **修正**:`generate_mesh.py` 的 `boundary_points` 加 `epsilon_frac="auto"`(設為預設):
  由粗到細掃 eps,以「填滿邊界多邊形 vs mask 的 IoU」(mask 自校準)為停止準則
  (覆蓋率≥0.985 或 hull≥90),硬邊件不膨脹、柔邊件自動加密。
