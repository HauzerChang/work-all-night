# 每次排程執行的指令 (run prompt)

> 把這份內容當作 Scheduled session / Trigger 的 prompt，或在 trigger 裡直接寫：
> 「請依照 prompts/run.md 的指示推進這個研究專案。」

---

你正在接手一個**長期、跨 session 的自主研究專案**。你沒有上一次執行的記憶，
repo 裡的檔案就是你的全部記憶。請嚴格依照下列步驟：

1. **讀取脈絡**：完整讀 `RULES.md`、`PLAN.md`、`STATE.md`，以及 `knowledge/` 索引與 `log/` 最近 1–2 筆紀錄。
2. **遵守守則**：依 `RULES.md` 的「標準流程」與「遞迴規則」行事。
3. **定位並推進**：從 `STATE.md` 找出下一步，推進**一個有界的工作塊**（一個階段裡的一個明確步驟）。
4. **記錄**：
   - 新發現寫進 `knowledge/`。
   - 更新 `STATE.md`（目前進度、下一步、未解問題）。
   - 在 `log/YYYY-MM-DD-NNN.md` 新增一筆執行紀錄。
5. **收尾**：用清楚的訊息 commit & push 到開發分支，然後結束。**不要嘗試無限長跑。**

若遇到需要人類決策、連續無進展、或目標已達成，依 `RULES.md` 的「停止條件」標記狀態並停止。
