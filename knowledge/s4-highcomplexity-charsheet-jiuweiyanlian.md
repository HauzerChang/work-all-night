## ⚠️ 取檔手法紀錄(可能是可重用的技巧,不是本次專案的核心產出,但值得記錄)

使用者透過對話直接貼圖(不是給路徑、不是走 SendUserFile 相反方向),這個排程容器**沒有
現成工具能把對話裡貼的圖直接存成檔案**——一開始用 `find` 找不到任何對應檔案。後來想到
Claude Code CLI 會把整個 session 的完整逐輪記錄(含 base64 圖片內容)寫成 JSONL 存在
`~/.claude/projects/<repo路徑>/<session-id>.jsonl`。寫一支小 Python 腳本掃這個 JSONL,
遞迴找 `{"type":"image","source":{"type":"base64",...}}` 這種結構的內容區塊,把 base64
資料解碼寫成檔案——成功從中復原出這張圖(連同這次 session 稍早我自己送給使用者的另外
3 張比較圖,一併被找到,不需要的直接不採用)。**如果未來又遇到「使用者對話貼圖但需要
存成檔案」的情境,這個手法可以直接複用**(找 session jsonl → 掃 image content block →
base64 解碼)。

## 圖片內容解析

不是單一角色插畫,是一張完整的角色設定資料表,多面板:標題/基本資料(文字)/面部細節
特寫/**服裝設計圖(正背面,含9個部件編號標註)**/**三視圖(正/側/背三個角度全身姿勢)**/
**表情設定(6張:冷傲/魅惑/微笑/挑眉/憤怒/自信)**/細節展示(耳朵/符印/吊墜/符紙/護腕
特寫)/色彩設定/氣質關鍵詞。

**這批面板裡最有價值的兩塊,不是主圖本身**:
1. **三視圖**——已經提供正/側/背三個角度的全身參考,直接回應
   `knowledge/s4-inpaint-taxonomy.md` 的「情境2(視角外推)」難題(原圖不存在的角度,
   補圖演算法原理上無效)——**如果這個角色要做轉身動畫,背面/側面參考已經有了,不需要
   生成式 AI 去猜**。
2. **表情設定**——6 張現成的臉部表情特寫,spine 常見做法是把臉部設計成獨立 slot、依
   表情切換 attachment,這批素材可以直接支援那套做法。

## 角色主圖裁切紀錄(供複現)

一點點標題文字/引言(未特別去除,不影響下游使用)。

## 角色本體的拆件難度評估(視覺判斷,尚未做任何實驗)

- 頭部(含狐耳)、上半身、雙臂、裙擺、雙腿:輪廓相對清楚,難度與既有機器人拆件量級接近。
- **長髮**:跟尾巴顏色高度相近(白到粉漸層皆有),交疊範圍大,邊界模糊。
- **雙臂白紗寬袖**:半透明材質,傳統「像素歸屬哪個部件」判定在半透明區域不可靠。
- **⚠️ 九尾狐尾(最大難點)**:九條尾巴顏色高度相近、彼此重疊、部分繞到身體前後——是
  `CLAUDE.md`「平圖未分層自動拆件・同材質語意召回0」問題的教科書級案例,傳統 CPU
  connected-components 完全無法把九條尾巴一根根分開(顏色/像素連通性上根本不可分)。
