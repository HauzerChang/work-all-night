# S3 端到端驗收 — 生成 mesh vs Award 真實藝術家 mesh(機器人拆件)

- **結論**:首次把 S3 生成器對照**真實生產 spine 的藝術家 mesh**(Award big win「機器人拆件」的
  3 個 mesh 件:光暈/左手/身體),而非合成或 main_draw 窗簾。**靜態覆蓋率上,生成器在調到與藝術家
  相當的 hull 取樣密度後,對全部 3 件都達到/超過藝術家 IoU,且頂點數相當或更省**。
  再次確認跨資產鐵律:**IoU 覆蓋率由邊界(hull)取樣密度決定,與內部點無關**。
- **信心**:高(對真實生產真值逐件比對 + hull 密度掃描單調關係 + 校準過的負對照)。
- **階段**:第 2 階段 / S3 × S4 端到端(PSD/atlas 件 → 生成 mesh → 對照真實 mesh)。
- **工具**:`tools/mesh_gen/validate_robot_mesh.py`(可重現)。

## 對照結果(atlas 切件 alpha 為來源;藝術家 mesh 為真值)

| 件 | 藝術家 v/hull/tri | 藝術家自 IoU | 生成(v1 預設 eps=0.008)v/hull, IoU | 判定 |
|---|---|---|---|---|
| 光暈 | 78 / 78 / 76 | 0.980 | 54 / 14, **0.929** | ✗(hull 太粗) |
| 左手 | 80 / 42 / 116 | 0.968 | 48 / 18, 0.960 | ✓ |
| 身體 | 98 / 40 / 154 | 0.976 | 61 / 21, 0.968 | ✓ |

- 光暈是**圓潤柔邊光暈(中心實心,非空環;bbox fill 0.44)**;預設 v1 只取 14 個 hull 點 →
  以 14 邊形逼近圓輪廓 → 覆蓋率掉。**不是拓樸類型問題,是 hull 解析度問題**。

## hull 取樣密度掃描(epsilon = Douglas-Peucker 容差)— 關鍵證據

`generate_mesh.py generate(eps)`;IoU 對 3 件皆隨 hull 點數單調上升,達藝術家 parity:

| eps | 光暈 hull/IoU | 左手 hull/IoU | 身體 hull/IoU |
|---|---|---|---|
| 0.008(預設) | 14 / 0.929 ✗ | 18 / 0.960 ✓ | 21 / 0.968 ✓ |
| 0.004 | 22 / 0.966 ✓ | 30 / 0.982 ✓ | 29 / 0.986 ✓ |
| 0.002 | 38 / **0.983** ✓ | 43 / 0.991 ✓ | 37 / **0.993** ✓ |
| 0.001 | 58 / 0.992 | 84 / 0.996 | 60 / 0.995 |

→ **eps≈0.002 時三件全達/超藝術家 IoU,且頂點數(73/67/77)≤ 藝術家(78/80/98)**。
**建議:v1 對圓潤/有機輪廓的件,預設 epsilon 0.008 太粗,調 0.002–0.004 即達生產 parity。**
(本 session 未改預設,避免未重跑 4-mesh 全套前動已驗證值;記為下一步可安全落地的 tuning。)

## 變形閘為何在此 N/A(重要範圍界定)

- **Award 的機器人 3 個 mesh 件在 12 支動畫全部無 deform timeline** — 它們是 **weighted mesh
  (靠骨骼權重變形),非逐頂點 deform**。故不能用「該資產自身真實位移場」當變形閘。
- 試以 main_draw 窗簾的真實位移場(313px 單向大拉伸)做**跨資產壓力**:對這些緊湊件 area_ratio
  1.2–2.1、出現自交 → **這是外來場 miscalibration,不是有效判定**(重蹈 stress_field / 合成場覆轍)。
- **教訓(再次)**:變形閘只在「同資產、真實、經校準的位移場」下才可信;把大幅外來場硬套小件會假性失敗。
  這些件真正的耐變形取決於**骨骼權重綁定**,超出目前 unweighted S3 的範圍。

## 評估器可信度(先驗校準)

- 藝術家 mesh 自身靜態 IoU 0.968–0.980(自一致性合理)。
- 負對照:**uv 亂序 → 0.82–0.88(鑑別力太弱,不可用)**;改**縮小 25% → ~0.55**、**平移 15% → ~0.53**
  → 正確 mesh ~0.97 vs 錯位 ~0.55,**IoU 閘確有鑑別力**。**教訓:負對照要夠強(位移/縮放),
  hull 序點亂序仍大致鋪滿形狀,是弱對照。**
