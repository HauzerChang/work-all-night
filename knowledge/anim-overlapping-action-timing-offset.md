# 動畫律動:各部位「時間差」(overlapping action / 慣性)— 使用者新增研究方向

- **來源**:使用者(2026-08-24)提出:「人物運動時,利用各部位的移動**時間差**,能讓律動更鮮活;
  類似物理世界的**材質運動與慣性運動**表現。」→ 納入研究。
- **對應動畫原理**:Disney 12 原則之 **Overlapping Action(重疊動作)/ Follow-Through(跟隨)/ Drag(拖曳)/
  Secondary Action(次要動作)**。核心:身體各部位**不同步**移動 —— 主軸先動,末梢因慣性延遲跟上、
  並在末端**過衝(overshoot)後回穩**。反面就是本專案痛點清單裡的「全身同步紙板感 / 待機僵硬 / 末梢甩不開」。
- **物理類比**:每個關節像被上游關節牽引的**阻尼彈簧(damped spring)**;質量/剛性 → 相位延遲(phase lag)
  與衰減。剛性高 = 幾乎同步(僵硬);剛性低/質量大 = 延遲大、擺盪久(鮮活但過頭會軟爛)。
- **信心**:高(下述在真實生產資產量測到,非臆測)。
- **階段**:第 2/3 階段;直接服務候選 **0d 分鏡→動畫 keyframe**(讓生成素材「會動且鮮活」)。

## 已量測:Award 真實美術**確實**用時間差(非同步)

用 `spine_skeleton` FK 對 `Award_Legend_Loop`(呼吸 loop,dur=1s)取樣各骨訊號,量到明確的
**外傳相位延遲**與**通道解耦**:

| 現象 | 證據(真實資料) |
|---|---|
| 沿骨鏈**外傳的相位延遲** | 大腿鏈 rotate 谷底時間逐節後移:`4_LEG4@0.500 → 4_LEG5@0.600 → 4_LEG6@0.667` |
| 末梢骨**落後**上游骨 | `4_LEG5 → 4_LEG9` rotate 互相關 lag = **+0.083s**(子落後父) |
| 同骨 rotate vs translate **不同步** | `4_LEG5` rotate 峰@0.133、translate.y 峰@0.600(通道解耦,增加層次) |
| 特效元件**錯開** | `光效1a`峰@0、`光效2a`峰@0.683;`光暈01`峰@0.783 —— 特效彼此不同拍 |

→ **結論**:同步(所有骨同拍)是「紙板感」的來源;美術靠 **10–100ms 級的逐部位時間差** +
末梢較大振幅營造律動。這正是使用者說的效果,且**可量化**。

## 可操作模型(供生成器,純 CPU、確定性)

給一段基礎律動訊號 `s(t)`(如呼吸的正弦、或分鏡關鍵姿勢內插),對每根骨 `b` 產生:

```
signal_b(t) = A_b * s(t - τ_b) + followthrough_b(t)
  τ_b            = 每骨時間延遲,建議 ∝ 骨鏈深度 / 到 root 的路徑長(外傳越遠延遲越大)
  A_b            = 振幅,末梢略放大(甩開末梢)
  followthrough  = 阻尼彈簧對上游角速度的響應(末端過衝+回穩);
                   x'' + 2ζω x' + ω² x = drive(上游)  → 低 ζ = 更活、過頭軟爛;高 ζ = 硬
```

實作要點(對接現有工具):
- 直接寫進 Spine `animations[*].bones[*]` 的 rotate/translate,用**緊湊 bezier**(雷點 #7)。
- 用 `spine_skeleton.world_transforms(anim,t)` 幾何自驗(不靠肉眼)。

## 評估器構想(遵守「每能力必配評估器」)

以 Award 為真值基準,對**生成的**律動動畫量測並比對:
1. **相位延遲剖面**:沿骨鏈量 lag(t),應**隨深度單調遞增**(外傳);與美術同號同量級。
2. **非同步度**:全骨峰值時間的分散(標準差)> 0 且落在美術區間(太小=紙板、太大=散架)。
3. **末梢振幅比**:distal/proximal 振幅 > 1(甩得開)。
4. **穩健性沿用**:`weighted_deform_eval` 的可見幀 0 自交/0 翻面(過衝別把 mesh 拉爆)。
5. **回穩**:loop 首尾連續(呼吸 loop 需 t=0 與 t=dur 對齊,避免跳幀)。
