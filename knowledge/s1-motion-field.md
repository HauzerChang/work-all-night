# S1 塊1 — 運動場提取 + 動態前景定位 + 全域運動特徵

- **結論**:S1 反推分析器啟動(先前卡在無影片,使用者已提供 benchmark 影片 `assets/robot_dance.mp4`)。
  第一塊 `tools/s1/motion_field.py` 用 Farneback 稠密光流,對真實舞蹈影片**成功定位動態前景 + 偵測律動**
  (3 AC 全過,exit 0)。運動能量圖揭示:**手臂/拳頭是主要動作源、頭中等、軀幹/腿相對穩定、背景靜態**。
- **信心**:高(對真實影片、機讀 AC + 視覺化佐證)。
- **階段**:第 3 階段前導 / S1(塊 1:運動事實提取)。

## benchmark 影片

- `assets/robot_dance.mp4`:chibi 巨獸機器人左右律動舞蹈。864×496、24fps、97 幀、4.04s。
- cv2 可直接讀(本環境無 ffmpeg,不影響)。角色類型 ≈ 我們手上的 `robot_parts`/Award 機器人。

## 方法(塊 1 只做最底層、可自我驗證的一步)

1. 逐相鄰幀 `cv2.calcOpticalFlowFarneback` → 每像素運動向量。
2. 累積運動能量圖(magnitude 均值)→ 閾值定位動態前景。
3. 全域特徵:動態像素(magnitude 前 8%)的水平/垂直平均流時間序列 → dx(左右)、dy(上下)。

## 結果(真實影片)

| 指標 | 值 | 意義 |
|---|---|---|
| corner/center 能量比 | **0.0001** | 背景幾乎全靜、運動集中在中央機器人(AC1 過) |
| dx 過零次數 / 振幅 | 48 / 5.94px | 明確左右律動(AC2 過) |
| dy 過零次數 / 振幅 | 23 / **21.89px** | 上下彈跳/手臂上下擺動,**幅度大於左右** |
| moving_area_ratio | 0.20 | 約 20% 畫面在動 = 機器人區 |

- **誠實發現**:雖然 prompt 稱「side-to-side dance」,光流量測顯示**垂直幅度(21.9px)> 水平(5.9px)**
  —— 手臂上下大幅擺動 + 軀幹上下彈跳,主導了動態像素。兩軸都強烈振盪(dx zc=48、dy zc=23)。
- 熱圖(`knowledge/figures/s1_motion.png`):最高能量在**雙臂/拳頭**與**頭冠**;軀幹/腿低。

## 對「反推需求規格」的初步啟示(待塊 2 分群量化)

- **手臂 = 主要可動件**,需肩+肘關節(大幅擺盪)→ rig 需要手臂子鏈(對應 rig_draft 的左手/右手掛軀幹)。
- **頭**中等動作(冠部醒目);**軀幹/腿**穩定 → 軀幹適合當 root(呼應塊5 `--root 身體` 才合理)。
- 這與現有 `robot_parts` 拆件 + `rig_draft` 骨架階層**方向一致**,可作 S1 產出的真值對照(召回率)。

## 自我驗證 AC(機讀)

- AC1 前景定位:corner/center 能量比 < 0.15 → 0.0001 ✅
- AC2 律動偵測:dx 過零 ≥4 且振幅 >0.3px → 48 / 5.94 ✅
- AC3 視覺化產出:熱圖 + dx/dy 曲線 ✅
