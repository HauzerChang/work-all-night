## 切圖規則框架(從動畫需求反推 — 運動決定拆件)

### 第一步:列動作清單(從圖片語義 + 情緒描述)
DJ 母貓刷碟、情緒高昂 →
| 動作 | 需要的獨立件 |
|---|---|
| 頭部節拍律動 | 頭(臉+兜帽+瀏海,兜帽跟頭動) |
| 貓耳擺動(情緒) | 左耳、右耳(這角色的耳=大型電馭耳板,含 LED) |
| 髮束甩動(次級動態,跟頭但延遲) | 左髮束、右髮束 |
| 左手揮拍 | 左手(掌+腕帶+前臂,切在上臂) |
| 右臂刷碟 | 右上臂袖(原 PSD 只給了手掌,袖子在身體層 → 補切) |
| 耳機物理彈跳 | 耳機(雙耳罩) |
| 胸腔律動/身體搖擺 | 軀幹(剩餘) |
| 轉盤旋轉 | 左轉盤、右轉盤 |
| (台身震動) | DJ台體 |

### 第二步:切線工藝規則(歸納自 Award 生產慣例 + 動畫常識)
1. **切在關節、藏在遮擋下**:切線放在自然色界(帽緣/腕帶)或會被上件蓋住的位置。
2. **重疊帶補繪(補圖前移)**:remainder 只補「殘留輪廓周圍 14px 重疊帶」——動畫分離只露出
   關節附近;把整個被切走的區域(整顆頭)都補成軀幹是錯的(v1 教訓:28k px 無據亂補 → 改帶狀)。
3. **旋轉自覆蓋件用 copy 不挖洞**:轉盤繞心轉永遠蓋住自己 → 複製成新層、台體保留原像素,
   零破洞風險(對照 Award:region 剛體件同理)。
4. **切割邊羽化 2px**:只羽化人工切邊(非天然輪廓),動起來不出硬邊。
5. **像素歸屬有優先權**:重疊區給上層件(耳>頭、髮束>頭、耳機>軀幹)。
6. **z 序 = 視覺遮擋序**:軀幹→袖→頭→耳→髮束→耳機→左手→台→轉盤→右手掌。

### 第三步:自驗(不能只靠肉眼)
- 重組閘:新 PSD 依 z 重組 == 原 composite(premult MAE < 2;實測 0.007)。
- 0 孤兒、13/13 件非空、逐件視覺板 3 輪迭代(v1→v4)。

## 迭代紀錄(失敗驅動,值得記)
- v1:耳機多邊形吞掉整個胸口(耳罩與胸部在 2D 同區,必須貼合耳罩**圓形輪廓**而非外框)
  → 改雙橢圓;耳朵偷走帽側;轉盤掃到混音旋鈕。
- v2→v3:頭頂沒切到 y=0(弧頂散落軀幹);耳罩/轉盤縮徑。
- v3→v4:轉盤重定位(實際中心 (197,12)/(566,12),比目測偏左 60px — 精修靠放大格線)。
- **工具鏈 bug 兩枚**:①psd-tools 中文層名 mac_roman 存檔炸 → 用 `layer.name` setter 寫
  luni 區塊;②程式生成的 PSD 重開後 `composite()` 回傳無 alpha 的扁平 preview → 閘假性失敗
  (alpha_mae 145)→ `psd_slice` 閘改 `composite(ignore_preview=True)`。

## 已知限制 / 待比對項
- 補繪是 cv2 級(重疊帶窄、多為平滑布料 → 夠用;大幅動作若露出更多需升級)。
- 表情(眨眼/嘴型)屬 attachment 換圖層級,不在幾何切圖內 → 美術版若有多表情件,是 AI 版的差距項。
- 切線精度靠格線目測(±4px);美術版的切線位置/件數/命名慣例是交叉比對重點。
- 尾巴/身體下半在 DJ 台後不可見 → 未切(美術版若有,代表他們用了原圖之外的資訊)。
