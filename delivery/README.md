# 研究成果發表 — A/B 對照(main_draw)

用 Spine 預覽器分別載入 `A/` 與 `B/`(各自的 `main_draw.json` + `main_draw.atlas` + `main_draw.png`),
切到同一支動畫(建議 `main_draw_open`、`main_draw_close`、`main_idle2`)左右對比。

- **A/** = 原始 `main_draw`,**完全未改**(對照組)。
- **B/** = 用本研究成果對 A 的 **4 片會變形的網格**(`curtain_left`、`curtain_right`、`shadow`、`shadow2`)做升級。
  骨架、骨骼動畫、時間軸、緩動、其它 36 個 slot **全部原封不動** —— 差異只在這 4 片布幕/陰影網格。

## B 對 A 做了什麼(全自動、無人工調點)

| 步驟 | 用到的研究成果 | 做法 |
|---|---|---|
| ① 細分拓樸 | **S3 v2 strip 生成器** | 把藝術家原本 21v/12v 的粗網格,自動細分成 64v/42v 的高解析度直條網格(頂點 ×3) |
| ② 動畫重建 | **deform 場轉移(平滑 RBF 重採樣)** | 把原本全部 **9 支動畫、共 40+ 個 deform 關鍵影格** 的變形,忠實轉移到新網格上;**時間軸與緩動 curve 逐格原樣保留** |
| ③ 品質把關 | **deform 幾何閘(deform_eval)** | 對每片×每動畫×每幀驗證;任一幀若平滑重採樣造成自交 → 自動退回線性(等同 A 的形狀,只是更密)→ **保證 B 幾何品質不劣於 A** |

## 量化驗收(全部自動量測,非肉眼)

**1. 忠實度 — B 的動畫形狀 = A(最大變形幀,填充 IoU):**

| 網格 | curtain_left | curtain_right | shadow | shadow2 |
|---|---|---|---|---|
| shape IoU (B vs A) | 0.985 | 0.986 | 0.974 | 0.958 |

**2. 平滑度 — 變形時邊界「轉折角」(越小越平滑,9 動畫平均):**

| 網格 | A(原) | B(升級) | 改善 |
|---|---|---|---|
| curtain_left | ~25° | ~11° | **↓ 55%** |
| curtain_right | ~26° | ~12° | **↓ 54%** |
| shadow | ~32° | ~13° | **↓ 59%** |
| shadow2 | ~36° | ~15° | **↓ 58%** |

**3. 穩健度 — 變形幾何品質(全部關鍵影格):**

- 自交(撕裂/破圖):A `0` / B `0`
- 三角翻面(貼圖鏡射):A `0` / B `0`
- → B 與藝術家原件**同級穩健**,細分沒有引入任何破面。

## 對比時觀察重點

1. **布幕自由邊 / 陰影邊緣的曲線**:A 在大幅開合(`open`/`close`)時邊界是**折線(polyline)**有稜角;
   B 是**平滑曲線**(轉折角砍半)。idle 系列的微幅波動也更柔順。
2. **切到線框 / mesh 模式**:B 的網格明顯更密、更規則(直條網格),布幕/陰影變形更綿密。
3. **整體動作、時間、節奏與 A 完全一致** —— 這是「不改動畫、只升級網格品質」的最佳化。

## 誠實範圍

- 這是 main_draw 既有的 **unweighted + deform-timeline** 網格,升級是「細分 + 平滑重採樣既有變形」;
  忠實度/平滑度/穩健度皆已量測。這**不是**改動作設計,而是**同一動作、更高的網格呈現品質**。
- 若某支動畫的原始變形本來就很小(如 `main_static`),B 的平滑差異在預覽器中會較不明顯 —— 屬正常。
